# Muse 自有知识库（本地，全文检索）

这是我自己的知识库，建在云电脑上，给我自己查资料用。
不是 Marvis 的知识库（那个在你电脑上），也不是 Notion 知识库（三套东西，别混）。

## 里头有什么

- 2026-11-10 建，索引 98 篇 Markdown、1441 块。
- 收录：`workspace/jiayisha` 与 `workspace/daishi-guanhua` 下的全部 .md，
  包括脚本、制作规格单、SOP 手册、风格手册、密度基准、对标拆解、事实核查、热点报告。
- 排除：Marvis 导入包目录（那 18 篇是复制件，避免重复命中）。
- 学习笔记：`知识库/学习笔记/` 下的自学笔记同样进入索引（2026-11-10 第一篇：写稿与审美，7 条规则）。

## 怎么用（我用）

```bash
cd ~/workspace/jiayisha/知识库
python3 kb.py 克隆音        # 查一个词，返回最相关的 8 条（文件路径 + 标题 + 片段）
python3 kb.py 密度 280      # 多词按 OR 匹配
python3 kb.py 秦红缨 --all  # 返回 20 条
python3 build_kb.py         # 新增文档后重建索引
```
