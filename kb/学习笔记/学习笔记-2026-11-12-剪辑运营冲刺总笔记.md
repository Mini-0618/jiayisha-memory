## 二、合并后的规则（按五站分组）

> 合并口径：同一动作在多轮重复出现时只留一条，括号内注明全部来源轮次；某轮明确修正/作废前轮规则的，以最新轮次为准并注明旧口径；凡写「经验基线」者先跑后校、不进硬验收线；凡写「待核实」者须先核再入验收线。

### ① 研究站

#### A. 研究关交付物：pitch 备忘录是总入口，核查日志是总底账

- **pitch 备忘录三行先行**：每条选题先写假设（可证伪的一句话）/ 最小故事（假设证不出来也值得发的版本）/ 最大故事（假设成立且挖出更大问题的版本），三行缺一不许开查；假设被证伪记进 D 库标「已证伪」不删。（R17-1）
- **pitch 备忘录里的页**（按需拼，不另立新表）：三墙卡（产业观察类必填，见下）、画像对照卡（R119-1）、主张清单首页（R66-1）、数据卡（R50-1）、财报五站速读卡（R126-1）、访谈提纲卡（R43-1）、系列卡（R20-1）、标题候选 3 个（R60-3）、模型卡五栏表（R147-1）、预印本核查工作表（R131-1）、论文一遍卡（R33-1）、收手标准三行（R17-3）。主片全套；切片与热点快评走精简版：假设一句话 + 最小故事一句话 + 线索表 3 行，10 分钟内填完，过不了就跳过。（R17-能力产物回应；R24-2）
- **线索表 → 核查日志同一编号流转**：线索表六列（线索/发现/来源/链接/参考日期/下一步）是研究关的工作表，定稿时线索行转核查日志行、编号保留映射（L-01…→S-01…），不是新增一张表；影像类线索单独编号 L-影像-01…。（R17-2；R27-3）
- **寻线两铁律**：人线——每次访谈/查阅结尾必问「还有谁懂这个、还有什么文件能佐证」；纸线——每份文件的脚注与参考文献必扫一遍。（R17-2；R43-3）
- **缺口稿是研究关内部件**：收尾时先写一版只列已证实/待查两栏的骨架稿，写出来才知道还缺什么；不许当成脚本开写，「研究不过不写稿」铁律不动。（R17-3）
- **收手标准前置**：最小故事可证 + 关键主张达到证据门槛（A 级一个或两个独立 B 级）+ 核查日志无「必须核实」的未结行，三条全满足即收手去做片；被点名的人与机构须查它自己的公开回应，查不到写「未见回应」。（R17-3）
- **研究关四清单**（事实/来源/数据/争议）每项标口径（已证实/争议/未证实）与证据层级；研究提示词里写明「不知道就写『未查到』，不许猜」。（R12；R123-2）

#### B. 原子化核查日志：一主张一行，因果单独成行

- **日志格式**：一行一个原子化主张，列：主张 / 证据来源（链接+文件标识）/ 证据层级 / 核查日期 / 结论；因果句拆两行（事实行 + 因果行，因果行默认标「未证实」）；数字主张另加基数 / 时段 / 绝对数三列，缺一项不许进稿；未证实的行对应正文里的一个弱化措辞或「剧情待核实」式标记，标记与日志行号一一对应。（R12-1）
- **结论四档**（R66-3 修正 R12 的三档）：已证实 / 矛盾 / 未证实 / 误导；旧「争议」改写为「矛盾」或「未证实」二选一，历史行不追改、只加备注。另有「查失败」状态（查过但未证实 ≠ 未查，分开记）。（R12-3；R66-3）
- **日志加列总清单**（同一张日志在全天内多次升级，合并为当前版；旧行不追改、只加列）：反方数/区间列（R21-2，v2.1）、限定词列（R66-2，v2.2）、图号列与读了几遍列（R33-2/3，v2.2）、转述手数列（R109-1，v2.2）、调查五要素列（R113-1，v2.2）、GAAP 对应数与分部来源列（R126-2，v2.2）、可用状态/版本/配置/第二源独立动作列（R144，v2.2）、演示验真列（R96-3，v2.2）、清洗记录列（R50-2，v2.3）、系数类数字标注（R146-3，v2.3）、幻觉型列（R123-1）、评测卡列（R56-1，v2.4）、拆分列（R147-2，v2.4）、存档快照列（R85-1，v2.5）、SIFT 四格 + 原文链接列（R100-1，v3）、版本列（R131-1，v3）、争议分型列与共识范围栏（R72-1/3，v3）、模型名行类型（R76-1）、引述行类型（R118-1）、影像核查栏（R27-1）、口播说法列与标尺换算列（R69-2/3，v2.2）、版本与测试条件列（R76-2）。当前版：**核查日志 v3**（2026-11-12 生效）。
- **措辞与证据精确匹配**：文件「显示」、某人「陈述」、某人「声称」、记者「无法证实」四种说法不是同义词；查过且查失败了，说出来本身就是报道。（R12 摘要）
- **数字进稿四道关**：百分比变化 vs 百分点；不同基数不比数量；移动基数（跌 20% 再涨 20% 回不到原点，演算写进日志备注）；小分母（总数＜20 的百分比必须并列绝对数）；百分比旁边并列绝对数，句中自带基数与时段。（R12-3）
- **数字双锚点**：任何产业数字进稿必须同时写来源 + 日期 + 证据层级，以及同一个数的反方数或不确定区间；每个投入数旁边必须配一个回收数（ROI / 自由现金流 / 收入）。（R21-2）

#### C. 证据分级与独立性：独立才是做功的词

- **肯定句门槛**：A 级一个，或两个真正独立的 B 级，可写肯定句；只有 C/D 级的主张，正文只许写「据 XX 称」或直接不写。证据四级：A 一手记录 / B 对记录的描述（DeepMind 博客属 B 级，不是 A 级）/ C 转述 / D 传闻。新闻稿/通稿/PR 稿只用来定位原始文件，定位不到时正文写明「据官方通稿」。（R12-2）
- **独立性校验**：两个人复述同一份简报是一个来源，两家互相引用的媒体是一个来源加一步；数第二个来源前先问「它是怎么知道这件事的」，路线不独立就不算数；两源救不了「没有任何来源能裁定」的主张（内心意图、无记录的私人谈话、没人统计的数字），这时报争议不报事实。（R12 摘要；R38-2；R100-2；R144-3）
- **转述链手数**：原文=0 手，官方博客/新闻稿=1 手，科技媒体报道=2 手，自媒体解读/短视频=3 手起；0–1 手可正常引用，2 手须回溯原文核对关键句，3 手及以上不许直接当事实用；热点快评 10 分钟内回溯不到原文的 3 手及以上来源直接跳过。（R109-1）
- **措辞升降级对照**：suggests/可能有关 → reveals/shows/揭示 → causes/prevents/导致、预防 → proves/证实 → 「所有/必然/颠覆」；标题的确定程度 ≤ 正文，正文 ≤ 来源；引用单篇研究/单次测试的主张，必须同时写样本量与人群。（R109-2）
- **SIFT 四步**（新信源 60 秒横向阅读）：Stop 停 / Investigate 查来源 / Find better coverage 找更好报道 / Trace 追溯原文；新信源第一次引用必须填「来源三行」；页面 About、Logo、设计精美度不作可信证据；走不完四步标「SIFT 未完成」、主张降一级；中文语境补充：搜主张时中文、英文各搜一遍。（R100-1/2）
- **追溯不到原文的主张不进稿**：真引言被截、真照片配假说明、真数字丢分母是最常见误导；数字主张必须追到原始文件/原始数据发布；引言类主张必须找到完整引言。（R100-3）
- **溯源链**：主张句 → 逐层上溯帖子 → 文章 → 原始文件/数据集/官方声明/访谈/研究，爬到原始出处或爬不动为止写明断链于第 X 站，链尾定级 A/B/C/D；链尾 A 级或两个真正独立的 B 级可进正式选题，只到 C/D 级只进待溯源区，断链且无第二路可走直接否决；单个候选溯源限时 20 分钟，超时按断链降级。（R38-1）
- **溯源档案随稿走**：主张句 / 溯源链 / 存档链接与取回日期 / 三态结论 / 未解决的问题；标题、封面大字、首句三处必须与正文口径同级。（R38-3）
- **存档核查**：关键主张先查存档改动史（主片关键主张必查，切片与热点快评只查有改动嫌疑的）；引用存档写五件（原页面 + 作者/机构 + 快照日期 + 精确快照 URL + 取回日期）；截图只当视觉参考，证据用带日期的存档记录；只有截图、没有存档记录的主张结论降一级。（R85-1/2/3）

#### D. 数字、跑分、调查、财报、模型名：各有自己的核查卡

- **跑分五问卡**：测什么 / 谁测的 / 什么条件下（版本、日期、尝试次数、提示词、工具权限、harness）/ 跟什么比的 / 还分不分得清高下；答不上来即降级措辞。跑分句死格式：数字 + 基准名 + 测量者 + 一句条件；禁裸数、禁跨 harness 比、禁把跑分写成模型属性。饱和与污染两条红线：引用前先查饱和（头部是否已扎堆 90% 以上天花板）与污染（题目是否公开、是否可能进过训练数据；查不到写「污染程度未知」）；任一项「未知」，措辞自动降一级。（R91-1/2/3）
- **评测卡六行**：数 / 测试名与版本 / 测的是什么能力一句话 / 谁测的（厂商自报 / 独立复现）/ 饱和状态 / 污染风险；厂商自报的单数不许写肯定句，须有独立复现或两个真正独立的来源；只有厂商自报的措辞降为「厂商称在 X 测试上得 Y 分」。（R56-1）
- **评测数三铁律**：饱和问先于排名（头部扎堆不许写「反超/碾压/最强」，只并列数字并写「该基准已近饱和，分辨力不足」）；污染问三问缺一结论降一级；数字只许写「在某测试上」，不许把「在 SWE-bench Verified 上 80%」写成「编程能力 80%」；一次只用一个基准比，不许拼榜。（R56-2/3）
- **调查数五要素**：谁做的 / 谁出钱 / 调查了谁 / 怎么问的 / 什么时候做的，缺一项即降级，缺两项以上直接不进稿。样本量两档：全国性口径 n≥1000 才算误差可控（1000 人约 ±3 个百分点，2000 人约 ±2 个百分点）；子样本 n<100 的百分比必须并列绝对数。原问题措辞四坑（同意倾向/引导性问题/问题顺序/社会期望偏差）；原问题是引导性或复合问题的，数字不许进稿；数据实际说的是什么 / 稿子想用它说什么，两行主语、对象、时间必须一致。（R113-1/2/3）
- **财报五站顺序读**：叙事（MD&A）→ 数字（三张表）→ 定义（分部附注/EPS 附注/非 GAAP 调节表）→ 风险（与 10-K 基线做差分）→ 流程（内控）；读之前先记文件身份（表格/accession 号/报告期/提交日期，四项缺一不许引数）。标题数字先过三问（GAAP 对应数 / 分部来源 / 现金兑现）；风险清单与 MD&A 只读「变了什么」；首次读某家公司先通读 10-K 风险清单全文一次并记基线，第二次起只读差分。（R126-1/2/3）
- **模型名四构件**：家族 / 代数 / 尺寸或档位 / 后缀，拆开写，写不全标「未证实」；能力数字进稿格式固定五项（模型全名 + 基准名与版本 + 分数 + 测试条件 + 来源层级），写不出的写「未公开」或「未证实」；代际比较只许同代比尺寸、跨代比代数；不许拿 base 模型分数当 instruct 版能力。工作室内部建「模型名对照表」（内部 ID / 厂商全名 / API 或工具内实际字符串 / 版本标识 / 用途 / 核查日期 / 状态）。（R76-1/2/3）
- **模型名进稿三件**：名 + 版本 + 日期，缺一件即标红；版本号变了，核查日志里旧行的结论不自动沿用，新版另起一行重核。只报总分的模型主张不进稿：进稿的数必须带拆分（分群 + 阈值 + 置信区间），三项缺一标「未拆分」。（R147-2/3）
- **模型卡五栏速读**：Intended Use / Metrics / Quantitative Analyses / Caveats / Model Details（版本 + 日期 + 许可）；五栏缺两栏以上，只许当「发布了」的新闻，不许当能力证据；主片研究关走九栏全套，热点快评只走五栏速读、10 分钟内填完。（R147-1）
- **预印本三规则**：版本状态四行（arXiv 标识符/版本号/发布与修订日期/有无期刊或会议正式版）；标题与钩子不许超过方法 + 局限撑得起的范围（边界三问：结论在什么数据集/基准/设定上成立 / 对照组是谁、比较公不公平 / 换一个评测设置结果还成立吗）；发布前 24 小时再查一次版本（新版本/撤稿通知/正式发表）。（R131-1/2/3）
- **论文三遍法**：一遍 5C 筛（Category/Context/Correctness/Contributions/Clarity，10 分钟内答五问，答不出两问以上或与选题无关即筛掉）；二遍只读图与证据（图号写进核查日志备注列；收口须能一句话复述「干了什么 + 凭什么证据」）；三遍只给核心论文（主片中心判断依赖的唯一来源，或数字/结论要写进旁白肯定句的论文；虚拟重做 + 挑战每个假设 + 凭记忆重建结构四段）。核查日志 A 级行加「读了几遍」列（一遍不许写肯定句、二遍以上才许、核心论文须三遍）。（R33-1/2/3）

#### E. 机制讲解与懂 AI：先摸清观众的心智模型

- **心智模型对照三行**（写稿前必填）：观众现在以为 / 技术实际是 / 这条缝拿什么桥；填不出来就不许动笔讲机制。（R6-1）
- **三层解释法**：L1 一句话（价值句）+ L2 一个真实例子（它实际怎么动）+ L3 技术细节（只进动态图形、字卡、作者补充评论）；每层自成一体；旁白每段机制只留一个新术语，出现时当场用一句话讲清。（R6-2；R14-1 修正：抖音无置顶，「L3 进置顶评论」作废，改为 L3 进动态图形/字卡/作者补充评论）
- **类比三关 + 反事实句**：类比映射的是机制的关键关系 / 不暗示 AI 有意识、理解、意图（禁「AI 明白/思考/学会了」，改用「按模式匹配/按规矩填/算出来」）/ 写清比方在哪失效；每段机制配一句反事实（「如果把 X 换掉，Y 会怎么变」），写不出说明机制本身还没吃透、打回研究关。（R6-3）
- **机制讲解三段式**（能力产物）：心智模型对照 → 一句话价值层（L1）+ 一个真实例子（L2）→ 反事实收尾 + L3 进字卡。（R6）
- **产业观察三墙卡**：成本墙 / 数据墙 / 能源墙各一行（当前数 + 来源 + 证据层级）；「投入产出/产业格局」类选题三墙必填，其他产业观察选题按需选墙、至少填一墙并写明为什么只填这一墙；三墙里有一墙写不出数的，选题先标「墙缺一」，不许用形容词顶替数字。（R21-1）
- **场景三分收口**：牛 / 基 / 熊三场景各一句话 + 转向条件；不许用「未来可期/挑战与机遇并存」式两头堵的结尾；讲变现路径时先问「这钱最后流向应用层还是基建层」。（R21-3）
- **产业判断**（能力产物）：AI 产业现在最大的矛盾不是「模型够不够强」，是「花钱的速度超过了收钱的速度」；最强反方是推理时计算、MoE、蒸馏正在把「用 AI」的成本打下来；回应：分清「训练方」与「使用方」两本账。（R21）
- **演示验真三规则**：build 一句话（「[东西] 接受 [输入]，产出 [可观察的结果]」，写不出来先标「未识别 build」）；剪切处与输入处是两道必查点（每一次剪切都问「切掉的是什么」；AI 角色三问：AI 帮写了项目？AI 在项目里运行？AI 产出了作品？）；复现分级（热点快评 10 分钟只查 build 一句话 + 输入输出链一处；主片级有仓库/可访问 demo 的跑一次干净环境复现；本地跑通只证明「这条路径在你环境里跑通了」）。演示视频的默认状态是「未证实」，不是「真的」。（R96-1/2/3）
- **AI 幻觉三型**：内在型（与来源矛盾）/ 外在型（来源证实不了的添加）/ 编造型（不存在的引用/数字/人名），另有一型专盯代码管线：包名幻觉（import 的库、npm 包名，安装前必须先查注册表存在不存在）。语气不是证据：只来自模型记忆、无来源的主张默认 D 级；「未查到」是有效结论，不是失败。防幻觉三招：先给来源再提问 / 换独立来源交叉 / 另起一段核验（CoVe 简化版）；热点快评精简版至少跑第一招，跑不完标「未交叉」。（R123-1/2/3）
- **模型选型三规则**：选模型先建自家评测集（50–200 条真实任务样本，按难活/量活/定活分三档；新模型与现用模型同跑评测集，报精度/延迟/成本三数）；四张牌打分卡（能力/许可/成本/部署，每张牌先写条件再打分，缺一不许进流水线；成本按我们的量重算）；混合部署 + 版本锁定（原型与难活走闭源 API；量活与定活走本地开源/租卡；关键路径必须有一条回退；切流流程：评测集同跑 → 5% 内微调补齐 → 非关键路径试点两周 → 特性开关切流 + 闭源回退 → 回退演练一次）。（R140-1/2/3）
- **AI 派活三规则**：派活前先估「人类工时」（任务书先写「人类专家做这段要多久」，超过当前实测时限的活必须拆段，每段人类工时 ≤ 当前实测时限；实测没做过时默认按「人类 30 分钟」保守拆）；新工具/新模型进工作室先跑一条至少 5 步的链（选题研究→事实核查→写稿→分镜→渲染参数），5 步全过的才进正式流水线；时限每季度实测一次（固定任务链、固定验收标准，跑 3 次取中位），旧数显式标注日期、不许悄悄沿用。（R136-1/2/3）
- **产品新闻四态卡**：官宣 / 内测·预览 / 灰度·分批推送 / 正式可用，四态 + 版本 + 地区 + 面向对象四行齐全才许写「已上线/已可用」；状态没查到写「状态未核实」。同名不同物先拆版本（模型版次或软件版本 / 硬件型号或配置 / 适用环境）。两家同稿不算两源：第二源必须带独立动作四选一（独立访谈/独立测试/原始文件/第一手观察）；结论前先写「还不确定」清单，热点快评里「还不确定」超过两项即跳过不发。（R144-1/2/3）
- **争议三型**：共识对孤证（按证据权重给篇幅，不许五五开）/ 真分歧（两边各给最强版本，结论只写「目前分歧在哪」）/ 无据可裁（报争议不报事实）；反方必须是最强版本（打稻草人进否决清单；孤证、过时研究、利益相关方说法不许和主流证据并列出场）；共识写清范围与日期（谁的共识/在什么问题上/截至日期），共识内部的分歧点写一句话，不许用「专家普遍认为」抹平。（R72-1/2/3）
- **X 算法漂移追踪**：锚点三件套不许从记忆里抄数（基准 commit 9106e9f 2026-10-31 10:25 + 最新 commit f06f45a 2026-11-11 11:52 + compare 链接）；只登记「变了且影响结论」的参数（home-mixer 值得进复盘的 8 项：点赞 FavoriteWeight 0.66→0.708、分享 ShareWeight 2.0→2.118、点击 ClickWeight 0.3→0.274、不感兴趣 NotInterestedWeight −52.272→−53.07、视频打开 VideoOpenWeight 0.02→0、HomeExcursion 开关 false→true、PhoenixAggregationType 改名加 HOME_EXCURSION、GrokAnalyzeWeight 新增 0.0）；home-mixer 与 vm-ranker 双文件分开记（点赞前者 0.708、后者 0.5）。（R61-1/2/3）

#### F. 影像核查、访谈与引述

- **影像三问**：哪拍的（主锚点 1 个 + 至少 2–3 个次要特征 + 视角一致，单特征匹配不算数）/ 什么时候拍的（影子/天气/植被/可见技术四条至少用两条交叉）/ 是不是最早出现（反向图片搜索 + 视频抽关键帧再反搜，找到最早上传版本与时间）；三问缺一的影像只许当「示意画面」并标注「地点/时间未核实」，不许当证据用。（R27-1）
- **元数据只当线索**：EXIF 易伪造、平台转发会剥离，只记在核查日志备注列，不进结论列；有且仅有 EXIF 支撑的影像主张，结论降级为「未证实」。AI 生成内容先过双查：反向搜索（搜不到更早版本 + 画面细节有破绽即标「疑似 AI 生成」）+ 查发布账号（新号、无历史、只发这一条，可信度再降一级）。（R27-2）
- **定位结论交证据链**：标注截图 / 地图资源链接 / 核查日期与时间 / 坐标（城市/场馆级即可）；定位前先列至少 2 个备选地点假设逐个排除（ACH 纪律），不许先定结论再找特征凑数。（R27-3）
- **访谈提纲卡**：目的三选一（拿信息/拿情绪与处境/拿回应），对象四分类（亲历者/专家/被点名方/旁观者），问题清单 5–10 条先易后难；提纲卡是研究关前置件。（R43-1）
- **引述三要素**：原话 + 出处 + 时间戳，缺一不许进稿（缺时间戳标「日期未核实」，缺出处标「未证实」，缺原话只许写转述「据 XX 称」+ 大意、不许加引号）；私聊与未公开渠道不许当原话引用，须先征得对方同意公开否则只能当线索。（R43-2）
- **访谈结束两问 + 24 小时内整理**：「还有谁懂这个」「还有什么文件能佐证」，答案进线索表；24 小时内整理（最强引述标星、待核实标红、惊讶点记进 D 库）；整理超过 24 小时须回放录音或重读原文再写，不许凭记忆补引述。（R43-3）
- **引述三问与来源分级**：原话在哪（精确到书名/演讲/采访 + 页码或时间戳）/ 谁说的（真人 + 身份 + 时间）/ 原话是不是这句（逐字比对，删节标「…」、改动标 [ ]）；可用来源顺序：原著全文 / 作者本人官网、原始演讲录音、采访原稿 / Wikiquote（须带出处）/ Quote Investigator / 权威媒体转述；Goodreads、BrainyQuote、A-Z Quotes、鸡汤 listicle、抖音截图 = D 级线索，只许用来发现「有这么一句话」。危险信号：归属时间晚于本人去世或活跃期；同一句话多个版本、多个「作者」；查不到最早出处时降级为「传」或删掉。（R118-1/2/3）
- **调查报道方法**（R17 摘要）：调查的本质是拿表现对照标准（法律、规章、社会规范）来量；单有一堆泄露文件不算调查——调查是泄露 + 公共记录 + 懂行的人访谈拼出来的；「文件心态」：默认任何一个官员或企业家的说法背后都有文件或数据能证实或证伪，先找文件再下判断；初稿是诊断工具；知道什么时候收手。

#### B. 钩子、缺口与开环：钩子之前必须先给够上下文

- **开头三备选**：写稿时每条片子强制写 3 个不同路数的开头备选（悬念/反差/奇观/痛点/冲突五类缺口选型），三个备选必须分属不同钩子类型；主片开头优先「悬念+痛点」或「悬念+反差」组合，切片开头优先痛点或反差；开头挖的坑正片必须老实填上，标题党一次就丢信任；反差必须立在真事上，禁编造假身份/假数据。（R1-2）
- **缺口单 + 倒 U 校验**：每条片子写稿前填三行（观众现在知道什么 / 还不知道什么 / 他为什么想知道）；倒 U 校验两端判否：观众对题材零上下文或答案已呼之欲出，两端都不合格；缺口必须具体到一件事、一个数、一个反常识点；开头三备选每个备选必须对应缺口单里已填的一个缺口，备选之间是不同缺口、不是同一缺口换说法。（R11-1）
- **开环/闭环列 + 微满足**：主环 0 秒开、结尾前收，不许在前 10 秒闭合；每段开一个小环，标明开环时间、闭环时间、环名；每 15 秒内必须有一个微满足（惊人事实/反转/部分揭示），超 15 秒无满足的段落标红补；切片至少主环 + 2 个小环，主片小环按章节开、每章至少 1 个。（R11-2）
- **闭环「超预期一级」校验 + 标题党四型否决**：闭环答案须比观众预期的高一级，写清两行对照（观众预期会听到什么 / 实际交付了什么、多出的那一级在哪）；只等于预期=平，高十级到不可信=假，不写对照的闭环不算过关。标题党四型禁入：永不闭环 / 闭环远低于承诺 / 文不对题 / 答案在别处。系列化只许用「答完生新问」作串联钩，不许用空吊的「下期揭晓」。（R11-3）
- **三环钩子法**：开头 5 秒开三个不同角度的环（信息/个人故事/反常），冗余保证至少一个咬住观众，再在不同时间点分别闭合；好奇心分三味（悬念·过去 / 悬念·未来式 / 戏剧反讽），峰值各不相同。（R11 摘要）

#### C. 语言节奏：密度是文案属性，写稿时设计，剪辑补不回来

- **句长谱**：口播稿每段画一条「句长谱」（数每句字数，短句 ≤10 字攒势、长句 25–35 字放势）；连续 3 句字数相近（差 ≤3 字）即标红，必须砍短一句或拉长一句；结论句、反转句单独成句，不许藏进长句尾巴；不改总字数——280–340 字/分钟的密度线不动，改的只是呼吸的分布。（R7-1）
- **标点即配音谱**：逗号=半拍、句号=一拍停、破折号=急转、省略号=拖尾；写稿时就把停顿标进稿子；一句话里逗号超过 2 个就拆句；禁逗号串联。（R7-2）
- **金句独占行与音韵**：最重的一句（结论/反转/判断）单独成行，周围留白当强调；每段只许一句金句独占一行；音韵只准在标题与金句用一次（须先过事实关，不许为押韵改词义、改数据），正文禁用刻意押韵。（R7-3）
- **口播句式「短—短—短—长」节奏型**（能力产物）：短（结论）—短（事实）—短（反差）—长（转折收尾）；备用变体：长句先行、短句收锤。（R7）
- **「对朋友说」过滤器**：逐句过，问「我会不会这样跟一个 26 岁的普通朋友说？」答「不会」就改；过滤器未过不许进配音。书面语改口语只动三刀（换词、拆句、去腔）；口语化不是口头禅化——「那个」「然后」「其实」「就是说」一句话里出现两次即标红；术语只留机制本身绕不开的那一个。定稿前大声读一遍 + 每季度抽查一篇主片稿「讲给朋友听」狠档，讲不出来的段落退回研究关。（R77-1/2/3）
- **数字口语化三步**：一句只许一个数字，一段（微块）只留一个明星数字进旁白；数字三步走：简化（四舍五入）→ 翻译（分数/比率/可想象的比较）→ 说清意思（so-what）；数字与限定条件必须同句出现。百分比只许一种说法，基数必须跟上（20%→30% 只能说「涨了 10 个百分点」或「比原来多了五成」，二选一并写清起点）；「翻倍/暴涨」必须跟基数；比率优先用「每 N 个人里有几个」「每秒多少」；30% 说「大约三分之一」可以，说「近一半」「大多数」直接否决。大数配一个观众能摸到的标尺（时间/人数/日常物三选一），标尺过类比三关；标尺换算须在核查日志里留演算过程。（R69-1/2/3）
- **删稿遍只删不加**：改稿第一遍只删、不加新句子、不改写；删的目标是时长预算（目标字数 = 片长 × 280–340 字/分钟），删到预算内即停；删完仍超预算，说明初稿结构本身超了、回分镜表砍段落。**括号法**：逐句问「这词在干新活吗」，六类括号件（动词后的空动词与赘饰 / 与动词同义的副词 / 陈述已知事实的形容词 / 弱化词 / 宣告句 / 整句重复上一句或告诉观众他自己能推出来东西的句子）；括起来，读一遍去掉括号的稿子，意思不变就删。**长词换短词**：建中文「短词表」（首版，随写随补），「进行/开展/实施 + 动词」→ 直接动词、「由于……的原因」→「因为」、「在一定程度上」→ 删或改成具体程度；冗余不只是啰嗦，是遮羞布——不敢下判断时，人会用长词把判断绕过去，先删长词、再把判断写成一句话 + 证据。（R132-1/2/3）
- **AI 味六项**（口播稿适配版，阈值标为经验基线）：①连接词密度：每 100 字「首先/其次/此外/总之/需要注意的是」＜1 个；②具体锚点：每段至少 1 个可验证的数字、专有名词或人名；③句长节奏：连续 3 句同长标红，每段须有一句 ≤10 字的短句攒势；④主动语态：每段至少一句以「我/我们」开头的主动句，禁「建议/应该」式无主语句收尾；⑤立场明确度：结尾不许「视情况而定/综合考量」，改成带条件的明确建议（「如果……选 A，否则选 B」）；⑥亲身细节：每篇至少 1 个真实踩坑、具体对话或真实数字。判定：六项命中 ≥3 条稿子打回重写，命中 1–2 条只改最痛的两项再发。改稿按四步顺序走（删连接词留骨架 → 植入具体锚点 → 打破句长节奏 → 加入「我们」的判断）；只换词不换句（「显著提升」→「大幅提升」）等于没改。**禁用词表 v1**：首先/其次/此外/最后/总之/需要注意的是/值得一提的是/不难发现/显著提升/增强体验/视情况而定/综合考量/建议开发者/深入探讨/深度剖析，命中即标红，改法是重写整句、不是换同义词。清单只审口播稿与标题（观众会读到的字），内部文件豁免；检测器分数不许进任何验收线。（R59-1/2/3）
- **段落二句法**：每段两句，第一句长句解释机制或事实，第二句 ≤12 字短句落地到人物动作或数据；段尾留钩子（每段结尾保留一个未回答的问题或动作余量，禁用总结句收尾）。（R57-2/3）
- **场景句开场**：脚本前 3 秒禁用抽象判断，直接写地点 + 物理细节 + 正在进行的动作；把形容词换成能被镜头拍到的名词和动词。（R57-1）

#### D. 结构与叙事：块是单位，环是骨架，脊柱是一句话

- **节奏三段验收**：注意力（前 3 秒观众还留在屏上吗）→ 进故事（观众能不能复述人物处境，脑子里有没有一幅画面）→ 情绪（结尾有没有一处共鸣点）；只有①过、②③不过的片子，判「快但不好看」——修法是补处境、补人物、补故事线，不是再加快。（R16-1）
- **密度与速度分开记**：节奏是「信息组织连贯 + 张弛有度」，不是越快越好；节奏曲线草图加一列「跟得上吗」——每段标一个观众自问；信息密度高但逻辑不断的段可以快，逻辑一断（新术语没讲清、新人物没交代、因果跳了一步）立刻降速、补一句承接再往下走；密度（每分钟信息点数）与速度（每秒切换次数）分两行记。（R16-2）
- **机制段先有处境再有情绪**：每段机制先问一句「观众脑子里有没有一幅画面/一个处境」——没有画面、只有论点与数字的段，情绪上不去；分镜表机制段加「画面/处境」栏；L2 的例子必须是一个有处境的场景，不许是抽象比喻。（R16-3）
- **微块结构**：3–5 分钟主片按「微块结构」剪——3–5 个微块，每块 45–100 秒、自带小钩子 + 内容 + 小满足，块间转场做注意力重置；线性结构禁入主片。微块检查单：前 10–15 秒有小钩子 / 至少一个小满足 / 结尾一句话勾住下一块 / 能量与上一块不同 / 观众能感觉到「在往前走」。块间转场固定三种（黑场过渡 0.8 秒、标题卡、音乐换层）。（R18-1）
- **五检查点**（按 4 分钟主片换算，片长变了按比例重算）：钩子 0–3 秒 / 第一实质满足约 40% 处（约 1:35）/ 中点重置约 50% 处（约 2:00，全片最危险的位置）/ 前高潮约 70% 处（约 2:50，stakes 拉到最高）/ 着陆最后 10%（约最后 25 秒，闭环 + 情绪落点，不许拖尾）。能量波：强度梯子（块 1 信息、块 2 加个人 stakes、块 3 加更广的影响、块 4 情绪峰值）；峰与峰之间留低谷；模式打断全片一次，落在中点重置处。（R18-2）
- **纪录片三角**：每块必问信息 / 叙事 / 情绪三边，缺一边即标红（缺情绪=讲课，缺叙事=清单，缺信息=煽情）。揭示结构：机制段不按逻辑顺序 1、2、3 排，按发现顺序剪；证据级联：证据按冲击力从弱到强排，每件证据都是一次小满足。反叙事：先摆观众以为的解释，再系统揭示它为什么不完整。（R18-3）
- **脊柱卡**：分镜前先交一句话脊柱（中心问题或一场转变，不是题材）；分镜表每块加「脊柱」栏；脊柱写不出来打回研究关。按转折点排结构（转折点 = 观众的理解变了的那一刻）；时间顺序只在一种情况下用（时间本身制造因果、压力或悬念，且须在分镜表里写明为什么必须按时间排）；结尾不许只做总结清单，须回到脊柱。结构失真三条红线进质检：因果（两段事实剪在一起，观众会不会读出「A 导致了 B」而核查日志里并无因果）/ 原意（引述剪辑后被引的人会不会觉得意思被改了）/ 示意（AI 生成帧、绘制占位、重演画面须标明「示意/AI 生成」）。（R45-1/2/3）
- **冯内古特三规则**：每句旁白至少干一件（推进故事或立住人物，两样都没有的句子删或改）；开场从离结尾最近的地方切入（先写结局句，开场第一句必须是结局句的近亲：结果/反差/代价三选一；开场三备选里至少一个是结局前置型）；悬念与信息早给分格式取舍（主片中心判断与关键数字在前 40% 交代清楚，留下的悬念是「怎么发生的、代价是什么」；切片悬念先行、信息后给，悬念句在前 3 秒）。（R37-1/2/3）
- **三幕式压缩**：每条片子先写「顺序版」，再重排成「张力优先版」——最有张力的一句事实提到第 1 句当筹码，背景只留看懂转折必须的 1–2 句；张力优先版第一句必须是缺口单里的主缺口；重排不是重写，事实一个不改。三幕时标按比例换算：筹码 3 秒内、背景 ≤15 秒、中点加第二个筹码、转折落点在片长 85% 之前；切片（45–60 秒）筹码 0–3 秒、背景 3–12 秒、升级 12–40 秒、转折 40–54 秒、收束 ≤3 秒。三个故事漏点进留存诊断对照：背景下垂 / 中段平坦 / payoff 来晚。（R86-1/2/3）
- **时间结构五选一**：顺时 / in medias res / 回溯框 / 双线编织 / 压缩时间；跳跃次数：切片只许一次，主片最多三次。重排只许延迟解释，不许制造假印象（四条诚实红线：不可以让观众以为某件事是某人的错/功劳而实际是另一个人的；不可以把分开的事件并成一场；不可以调换因果；不可以把后来的理解提前到当时）；还原测试：看完片子观众必须能按核查日志还原真实时间顺序；定位信号每跳一个、且只一个。（R106-1/2/3）
- **伏笔三触点**：先写结尾的「恍然大悟」句再埋；埋点只占一两句、混在另一件事里，不许旁白点破「这是伏笔」；主片埋（前 30 秒内）→ 再提（中段，换个样子、多一点怪）→ 收（结尾前，复现埋时的原词/原画面/原感觉）；切片只许埋 + 收两触点；收法只许行动/画面复现，禁旁白解释「其实那时候……」。伏笔登记表一伏笔一行（埋点/再提/收点时间码/状态）；有埋无收须当场处理（照原计划收/小小地收/与别的伏笔合并/不再放大）；不收的伏笔不许进封面与首帧钩子。（R94-1/2/3）
- **段落衔接三规则**：每块首句必须是承接句（半句收上一块 + 半句开下一块）；承接词按逻辑关系选（递进/转折/举例/因果/总结五类配口语说法；禁「首先/其次/最后」与「接下来我们讲/下面我们来看」；同一条片子承接关系至少用两种）；衔接别扭先查块大纲（修法顺序：调块顺序 → 删块或合块 → 中间补一块过渡块 → 最后才改承接句）。（R99-1/2/3）
- **转折句三规则**：转折先定关系再选词（分镜表每处接缝先在「关系」栏写一个词，五选一；「但是/然而/不过」只许用在真转折处；句首显性转折词每段最多一个，全片不许连续两段用同一个词开头；删词测试：删掉转折词后意思不变的，删）；Known + New 接缝法（转折句首句重复上段的具体名词、数字或画面，再带出新信息；禁以「这/那/这就意味着/这说明了什么」空代词开头；「也就是说/换句话说」一稿只许用一次）；章节级转折必须带锚点（时间/地点/视角三者至少给一个；空切禁入）。（R116-1/2/3）
- **结尾收束五段式**：主片收尾 20–40 秒，固定顺序（收尾句 → 证据回扣一句 → 三点以内回顾每点一句话动词开头 → 下一步：系列下一期题目或评论区讨论题二选一 → 一个 CTA：关注系列/收藏/评论三选一，点名具体东西）；45–60 秒切片只留收尾句 + 一个 CTA 两件，5–8 秒。收尾句先写，倒着写稿（先定收尾句再写正文朝它走；收尾句必须过遮名测试与一句话判断测试）；结尾禁三样（禁新概念、禁长篇感谢、禁四个动作一起喊）。收尾单独审：收尾八问（观众能一句话说出得到了什么吗；判断回来了吗；有没有新概念混进来；回顾超没超三点；下一步是必然的延续吗；CTA 只有一个吗；CTA 点名具体东西了吗；收尾句换别人也能写吗），八问有一问答不上来整段收尾重写。（R53-1/2/3）
- **峰终定律**：每条片子写稿前先定「峰与尾」两句（峰值句落在约 70% 前高潮处，结尾句落在最后 10% 着陆块；两句未填不许动笔；峰值不许是「最长的一段」或「信息最多的一段」）。结尾三件套：收口（主环闭合）+ 串联钩（答完生新问，只许一句）+ 停顿（金句后 1 秒静音再出片尾），三件缺一件结尾不算写完；拖尾禁入。负面峰值先修，修不掉不许靠结尾盖；每条主片至少一个正峰值，切片正峰值就是钩子后的第一个小满足。（R111-1/2/3）
- **记忆曲线**：每条片子只许定一个「必须活过今晚」的记忆点（写成一句 ≤20 字的话，必须是判断句，能被观众原样复述给别人听；片内至少复述 2 次、每次换形不换意思；同一句话原样说两遍是注水；多于 3 次先问一句「是不是在注水」）。每个关键信息点必须挂在一个挂钩上（三类挂钩：情绪/已有认知/具体场景三选一，没挂钩的不许进正片，只许进字卡）。结尾 30 秒是观众记忆的最后一次复习窗口：记忆点必须在结尾前再出现一次，且以判断句收束；收束句必须就是记忆点本身，不许结尾另起一句新判断。（R142-1/2/3）
- **人称站位**：每微块定一个人称主导（我/你/他），一块一人称；钩子块用「你」，判断句用「我」，机制段用第三人称限定，全知禁入；结尾着陆块允许一次有标记的「你→我」切换。「你」只许用于可核查的共同经验，不许替观众下结论（「你一定/你肯定」一律改条件句）；「你」只许出现在钩子块、处境句、结尾主问题三处，机制段与证据段禁「你」。「我们」禁偷运共识（禁「我们都知道/都明白/都清楚」「普遍认为」）；「我们」只许指真实共同行动（「我们查了论文原文」）；判断句必须用「我」认领。（R63-1/2/3）
- **对话写作**：开写前先填两句目标句（「A 想让 B ______」「B 想让 A ______」，动词只许用能演的：拖延、逼认、试探、收买、逼退、求饶、栽赃、留住；「聊聊」「谈谈」「说说」不算目标）。每场对话画三层图（公开话题/当下目标/埋藏需求），每句台词至少在两层上工作；说明信息进对话前过四问，然后必须让信息变贵（信息一出口，权力、信任或选择三者至少其一发生变化）。对话改稿分五遍（目标 → 潜台词 → 声音 → 压缩 → 表演），每遍只干一件事；动作替台词在前。（R41-1/2/3）
- **社会观察三规则**：田野笔记三栏法（事实/判断/待核实分栏，事实栏禁价值判断形容词，只许留可核实描述词）；具体性阶梯（抽象词下钻三级才许进稿；块 01 第一句旁白必须含一个可拍细节）；厚描写预算 + 划掉第一版（每段只留 1–2 个「一词多工」细节；开场细节先写 3 个备选、划掉第一版，三个备选须分属不同感官）。（R32-1/2/3）
- **认知负荷三规则**：一个微块只装一个新组块（每微块 45–100 秒只引入一个新术语/新机制/新数字组；新组块 >1 即标红；信息点要「成块」，同属一个组块的 2–3 个信息点算一个组块）。双通道分工，禁双通道打架（旁白讲机制，画面讲证据/处境；字幕只出现关键词与数字）。每块结尾留一个「取回点」（主片至少 2 个：中点重置处 1 个 + 结尾 1 个；切片至少 1 个：结尾提问；取回点不许是「看懂了吗」式封闭提问）。（R81-1/2/3）
- **历史叙事三规则**：历史段先布景再讲事（完整场景四件：地点/时间/气氛/对抗；主片至少一处完整场景，须落在钩子块或前高潮处；切片至少一句场景锚点）；细节只用「有出处的一处」（每段历史主张配一个 telling detail，须标核查日志行号；甲乙两个来源说法对不上时，把矛盾本身写出来）；禁编造对话与内心（没记录的对话一律不许写进旁白；「他当时想」须有日记/书信/录音作证；人物表情须有来源）。历史稿按「章章递进、段段悬念」排（微块结尾留钩；每 1–2 个微块跳出叙事做一次「到哪了」小结：走到哪了 / 证据允许我们合理相信什么 / 各方此刻的赌注与犹豫）。（R29-1/2/3）
- **人物塑造三规则**：每条主片写稿前先填「人物卡」三行（欲望/独特性/复杂性，三行缺一不许动笔；欲望必须有一件可核查的行为或言论佐证；独特性必须是事实不是形容词；复杂性至少一层处境、代价或矛盾）。人物只取「与剧情相交的那一面」，关键点 3–5 个、按 25/50/25 排进微块（块 1 约 25% 立人物与欲望 → 中间块约 50% 走旅程与关键点 → 结尾块约 25% 收情绪与判断，旁白不许替观众总结）。人物用行动与原话立起来（他做过的事 / 他说过的话 / 别人对他的反应）；禁三样：形容词贴标签 / 编造的内心独白与未记录的对话 / 把人物写成完美的白帽或全黑的反派（复杂性要求正反两面都有据）。（R22-1/2/3）

#### E. 论证、反方与说服：反方越弱，判断越不可信

- **反方先定级**：思考单「最强反方」栏必须标 DH 级，DH3 以下不算反方（DH3 只把反对意见说出来，不给证据与推理，是口号不是反方）；主片每条中心判断的反方必须到 DH4，中心判断本身的反方要到 DH6；切片反方至少 DH4。定级标准：DH4=反方 + 一条推理或证据；DH5=引用对方原话并指出它哪一句错了；DH6=先明说对方中心点是什么，再驳中心点。（R25-1）
- **反驳先复述对方中心点**：DH6 模板——「对方的中心点似乎是 X。正如他说的：『一句话原话或出处』。但这不对，因为……」；反方段三行：对方中心点一句话 / 引用或出处 / 驳点一句话；找不到一句可引的原话、只能写「有人认为」时，先在思考单标「稻草人风险」。（R25-2）
- **低层级反对不配实质回应**：DH0 谩骂 / DH1 人身 / DH2 语气抱怨，只回一行或点赞代替，不展开辩论；同一 DH2 意见出现 3 次以上，记进复盘台账当信号；DH3 矛盾回一句带证据的反问；DH4+ 才值得展开聊、补信息、甚至转选题。自家稿子禁三样：禁人身、禁嘲讽语气、禁纠小错冒充驳倒；引用了对方原话、接着只给 DH3 级回应的，红队直接判「假反驳」。（R25-3）
- **反驳金字塔实操**（压缩轮 R51）：分层反驳表（从 0–7 级逐级标定，写稿前先写反方最强 7 级再压缩到 5 级发表）；先肯定，再替换（每段先一句承认对方可信处，再用数据替换，口播稿加「我承认……但……」模板）；不攻击动机（凡出现「他只是想……」立即删掉并换成事实）。
- **反方前置三规则**：脚本思考单强制加「最强反方 + 一句话回应」栏，空着不许进写稿（反方须能点名来源或引用评论区原话，捏一个「有人说」不行）；结论前先亮剑（开头钩子 → 40–60 秒处明说反方 → 90 秒内用机制/数据/实证收束；反方在哪里、回应在哪里，两个时间码差 >50 秒即打回）；回应只许用三件里的至少一件（机制、实测数、场景），禁「感觉/普遍认为/大家都说」。（R127-1/2/3）
- **ELM 双路线**：写稿前先判「路线」（相关性 × 能力两维）；片头 3 秒默认走边缘路线（钩子、处境、可信信号开门），中央论证只能后置，第 1 个微块之后再转入。中央路线段只许一个论证（每段机制只留一个核心论点 + 一个最强证据 + 一句反事实）；边缘线索（可信信号/处境画面/节奏与音乐/作者一致性）在分镜表标 P，不许伪装成中央论证；「很多人都这么说」「120 亿播放」不是论据。核心判断必须走中央路线验收（须有证据、有反方回应、有可复核出处，三件缺一不许进稿）；复盘时中央指标（收藏、复访、评论里有人复述判断、有人拿判断去反驳别人）与边缘指标（播放量、点赞数、3 秒留存）分开记；只涨边缘指标、不涨中央指标 = 「好看但没说服人」。（R102-1/2/3）
- **措辞分级五级**：A 级已证实 → 肯定句；B 级可信 → 「据 XX」；争议 → 「一种说法是」；未证实 → 「还没法确认」；预测 → 「可能」。绝对词黑名单（无 A 级证据时禁「这证明了」「真相是」「所有人都知道」「毫无疑问」「彻底颠覆」）；「批评者说/很多人认为」不说清是谁、多少人禁入。每句旁白先打三类标签（事实句/判断句/推测句，标签与核查日志行号对应；无行号的事实句不许进稿；推测句只许用「可能/或许/如果……会」且必须同时写清「不知道什么」）。归属链检查：每句重要主张问一句「错了能追到谁头上」，追不到具体来源又不是我们自己判断的句子三选一（补归属/降级措辞/删）；禁孤句引用与反应代事实（「网上都在传」「舆论炸了」不许当论据）。（R65-1/2/3）
- **框架效应三规则**：判断句写稿时强制写「双框对照」（每条核心判断在思考单里写得益框/损失框/选框理由三行；选框理由只许三类：事实本身就是得益/损失那一侧；观众当下最在乎的那一侧；红队审过；禁同一事实在同一条片子里两框混用；为煽动选损失框禁入）。数字句先报绝对数再选框（格式死规矩：「X 里有 Y（占比 Z%）」——分子、分母、总数三数齐全；标题与钩子可以用框，但正文第一句必须把另一框的数补上；稿子里出现「涨/跌/多/少」必写「跟谁比」）。目标框架只许「帮观众避坑」，不许「吓观众点开」（损失框三条使用边界：损失必须是真的 / 损失必须可核查 / 损失框只许用在钩子与结论两处，全片损失框句子占比不许超过 1/3；标题尤其禁「不看就亏了」式损失框标题）。（R138-1/2/3）
- **损失厌恶三规则**：讲「会失去什么」之前，先在思考单里填「参照点」（观众现在的参照点是什么 / 我们讲的是「保住它」还是「得到新东西」/ 这句话在观众脑子里会被编码成损失吗）；损失框架只许用在真实存在的损失上，不许凭空造一个参照点再恐吓。损失句全片限量（主片 ≤1 句，45–60 秒切片 ≤1 句，超了打回），且出现后 10 秒内必须给一个可执行的「保住」动作；禁句型：「再不…就…」「错过这条你就…」「90% 的人都…」；翻法优先：把「怕失去」翻成「保住已有」。系数「约 2 倍」不是常数（拟合值约 2.25，Tversky & Kahneman 1992，但随赌注、个体、测量方法变）；稿子里要么不写数字、只讲方向，要么写「大约两倍（经验估计，因人因事而变）」，不许写成定论句。（R146-1/2/3）
- **分享触发器三规则**：每条片子写稿前定一个「主分享触发器」（社交货币/实用价值/情绪/身份/对话五选一主、最多再配一副；三行必填：谁会转给谁 / 转的时候会说什么 / 转了显得自己怎样；情绪触发器只许选高唤醒：敬畏/惊讶/建设性愤怒）。分享时刻前置 + 零上下文可转（分享时刻通常在情绪或认知峰值处，不在片尾；放在片长前 60% 以内，切片放前 30 秒；片尾只留 payoff 与系列钩子）。愤怒只许对系统、不许对个人（建设性愤怒针对系统/机制/模式，落点是「可以修好、怎么修好」；暗分享三型：嘲讽分享、仇恨观看/猎奇分享、争议种田，一律进否决清单）。（R120-1/2/3）
- **互动目标三规则**：每条片子写稿前先定一个主互动目标（收藏/转发/评论/完播四选一；点赞不设主目标）；收藏与转发分开设计，不许一句「点赞收藏转发」打包喊（收藏 CTA 只许放在价值交付后约 70% 处，口播一句「收藏起来，下次……用得上」，须说清「下次什么时候用得上」；片头与片尾不许放收藏 CTA；转发动作：身份句 + 反常识数据或真分歧，争议须两面讲公道）；互动率按信号分开记、按自家基线判（点赞率/评论率/转发率/收藏率四列分开记，各自 ÷ 播放量，每列与同格式最近 10–20 条中位数比，不许拿外网阈值当验收线）。（R143-1/2/3）

#### F. 幽默、标题与金句

- **幽默三规则**：笑点只从真东西里找（三来源：亲历/观察/事实反差；禁三样：凭空编的段子、网络烂梗与谐音梗、拿观众或被点名的人物当笑料；自嘲只许拿自己开刀；笑点不许改事实）。笑点用「先铺后拧」（铺垫是观众认得的日常，拧在句尾，铺垫里不许泄底；主片每微块最多 1 处，全片 3–5 处；切片最多 1 处；拧之前按标点谱留半拍停顿）。先赢信任再开玩笑（前 30 秒先立判断与证据，不许开场先抖包袱；严肃段禁笑；笑点三问：这句好笑是因为真，还是因为夸张到假 / 观众是跟我一起笑，还是被我笑 / 删掉它片子还成立吗；自嘲每段最多一次）。（R19-1/2/3）
- **吐槽式过渡**（R124）：「夸大→拆穿」的两拍结构，三行内收尾（第一拍说一句观众以为你要吹，句尾留空；第二拍用「不是/别/其实」拆穿，落到具体动作或数据；句长每行 ≤18 字）。幽默禁形容词堆砌，只用动词（删掉「非常/超级/非常厉害」的修饰；口播稿过筛：出现两个形容词连用，直接标红删一个）。自嘲先于自嗨（落脚点是「我在某处也翻车」，不是「你应该」；每个主片脚本开场 30 秒内，必须插入一句自嘲式卡点）。
- **简写轮 R134**（与 R124 同题同源，PG《Write Simply》）：每段旁白只保留 1 个谐音梗或反转，超过 1 个就删（脚本检查清单「幽默计数≤1」）；梗必须带具体名词，不能用「你懂的」替代（写稿模板强制「具体名词+对比」）；不许自嘲超过 3 秒，超过即切回事实句。
- **标题三规则**：标题三步卡（先填交付/目标/悬念三行缺一不许写标题，前两行过即完成 85%，悬念四杠杆选一、数字须过研究关，成片前补满 10 个备选定 1 个）。每条主片写 10 个标题备选意思必须不同（四型各 ≥2：好处/痛点/回击质疑/证据 + 自由 2 个，换同义词不算新备选，须过「26 岁普通人 3 秒读懂」，禁「保姆级/全流程/90% 的人/一条讲透/绝绝子/建议收藏」烂梗）。标题先写后锁（选题会定 3 个候选，成片后做承诺—交付复核，换标题重测一次只换一个变量，长度暂行「一屏读完」验法、截断口径待核实不写硬字数）。（R60-1/2/3）
- **金句三规则**：金句三要素验收（真：须有核查日志行号；短：≤18 字，一句字幕装得下；落点：重音词在句尾最后一个词上，三项缺一不许进稿；主片每微块最多 1 句、全片 2–3 句，切片最多 1 句）。金句五步工作室版（从已证实的行出发，找张力、砍承重、给节奏、冷测 + 反转测试：反过来也同样成立的打回）。金句只许出现在三个位置 + 查重（中段反转处/结尾收束处/封面标题；开场 3 秒与前 30 秒不许金句；定稿前搜原句，撞名句改写或注明来源，撞自己旧片金句改）。（R74-1/2/3）

#### G. 类比的写法：先讲清、后比方

- **先讲清、后比方**：机制段先给 L1 一句话事实再上比方；「抽比方测试」——抽掉比方句后机制还讲得清才算过。（R90-1）
- **比方从机制关键关系长出来**：三步（关键关系 → 观众日常物 → 失效边界写进批注）；优先用专家自己用的比方；禁须先懂另一件事的比方、禁拟人动词。（R90-2）
- **比方有预算、有刹车**：每段机制最多一个比方；全片延伸比方只许一个，须登记每一处回扣点；四种死法（装饰型/拉太远/陈词滥调/误导型）进否决清单；能不用比方讲清就不用。同一比方全账号用满 3 次即入陈词库，「AI 是大脑」「算法是黑盒」「数据是石油」即刻入陈词库。（R90-3）
- **反模板检查**（R71-1，简写轮）：选题前过「反模板」检查，三句话判定是否有独特判断或真实场景，无则重构。

### ③ 制作站

#### A. 片头、封面与首帧：首帧即钩子，封面是独立设计件

- **片头三件套同步，缺一不可**：画面——第一帧必须有信息，禁黑屏淡入、禁 Logo 片头、禁空镜开场；花字——钩子最扎眼的三四个词用最大号钉在首帧正中或偏上，静音刷也能看懂；声音——第 0.1 秒即有动静（第一句台词、脆响音效或 BGM 最炸的鼓点直接切入）。审片加两步：静音看前 3 秒能看懂要干嘛吗？闭眼听前 3 秒想拿起来看吗？两项有一项不过就返工片头。（R1-1）
- **片头 6 种死法进质检否决清单**：①上来先报家门「哈喽大家好，我是……」；②慢悠悠摇蓝天白云/空房间铺垫；③开头喊「惊天大秘密」，正片却是大白话；④钩子铺垫超过 3 秒还没讲到正题（8 秒是死刑线）；⑤虚话「今天教大家一个绝招，很多人都不知道」；⑥首帧黑屏/片头动画/没对上焦。冷开场默认动作：把正片最强的一句台词或最强的一帧画面提到第 1 帧，上下文后补；主片开头 3 秒内必须出现一次切镜或画面动势，不许静止超过 3 秒。（R1-3）
- **封面三要素**：单一焦点（只留一个最强元素：一个数据字卡、或一张对比图、或一帧最有冲击力的画面，多元素拼贴禁入）；大字 3–5 词（只写画面说不清的那一句，标题已有的词不许重复进封面，粗体、带阴影或色块、与背景拉开对比）；品牌强调色固定（春有信暖琥珀 #E8A04C 或明有期冷夜蓝 #16283F，霓虹青 #57C7D4 作点缀，边框/文字底/小标记全片系同一色，不许每条换色）。验法：缩到手机列表尺寸（约 200px 宽）看一眼，焦点与大字还认得出才算过；裁切区不放关键信息（抖音主页展示裁切口径待核实，以创作者中心实际显示为准）。封面图单独出，不许用渲染默认首帧顶替。（R13-1）
- **首帧 = 封面的动态版**：字幕先行（钩子词首帧即以花字出现，静音刷 1 秒内看懂要讲什么；花字词必须与封面大字是同一句话或同一缺口）；0.3 秒动势（首秒内必有一个 deliberate 的动：推近 100%→105%、文字滑入、数字计数动效，静止首帧禁入）；2 秒内给 payoff（微预告之后立刻跟一句「对我有什么用」，不许预告完又铺垫 5 秒）。视觉对上承诺：封面/钩子提到数字，首帧 2 秒内闪对应数字字卡；提到对比，首帧闪对比图；提到问题，首帧闪问题字卡。（R13-2）
- **封面一次只测一个变量**：每条主片出 2 个封面变体，一次只换一个变量（焦点换/大字换/强调色换/动 vs 静首帧）；同一片换封面重测时，换封面前后时段分开记；指标：点开率（播放量/曝光量，创作者中心口径）为主，3 秒与 10 秒留存 + 平均观看占比（自家基线法）为副；点开赢了、3 秒留存跌了的变体判负；测试跑满 24–72 小时再判；同一改动连测 3 条同类片子再定。（R13-3）
- **系列片头标识 1 秒**：标识放在钩子句之后（主片约 0:03–0:04 处），不许放在第 0 秒；标识只有一件事：告诉观众「这是《AI 机制讲清楚》系列」，干完立刻进内容；标识之后不许重启介绍。信号只许系列名字卡「AI 机制讲清楚」（固定字体、字号、位置、固定色：明有期冷夜蓝 #16283F 底 + 霓虹青 #57C7D4 缺口线）；动作只许一个动效创意（霓虹青缺口线自左向右一笔画过、落定为系列名）；声音只许一个短音色签名（低音 whoosh 进、一记轻落音收，电平低于旁白）；过渡要消失（标识落定后 0.2 秒内切入第一内容帧）。标识用留存验：第十次观看测试（连看 10 遍，第三遍就开始烦的标识先缩短、再考虑删）与留存点验（复盘时看留存曲线在标识开始的那一秒约 0:03–0:04 有没有跌，单条跌不判，几条同格式片子都在同一点跌才是信号）。45–60 秒竖屏切片不设独立标识，系列识别只靠角标小字 + 固定色。（R133-1/2/3）

#### B. 字幕、字卡与出处标注

- **字幕三数进自动校验**：单行 ≤18 字、CPS ≤9、单条 0.85–7 秒；旁白 280–340 字/分钟 ≈ 每秒 4.7–5.7 字，远低于 9 CPS 上限——字幕超速的唯一来源是「长句一口气不停顿」，解法是按语义断条、不是放慢语速；单行上限沿用已定的 18 字，竖屏切片收紧到 10–14 字；单条最短 0.85 秒（极短回应延展到 0.85–1.2 秒防闪烁）、最长 7 秒。（R2-1）
- **断行三原则 + 标点全片统一**：①未满上限保持单行，不为视觉对称硬拆两行；②必须双行时在标点后或连词（但/因为/才/如果）前切，优先上短下长，禁拆词、禁第一行只剩一两个字；③整句超约 24–32 字、有明显换气停顿或单条将超 7 秒，直接拆成两条独立字幕。标点统一：全片不用句号（。）、行尾不留逗号顿号；句中逗号与半角空格二选一——定为保留全角逗号，全片不许前半段逗号、后半段空格；数字用半角、书名号《》引号「」照用，但记住它们占字数额度（一组《》+一组「」= 4 字，实际汉字只剩 12 个）。（R2-2）
- **跨条连续句不加省略号，竖屏字幕上移**：同一句话只因超字数拆成前后两条时，两条都不加省略号；只有说话人真实犹豫停顿、话说一半被打断、被画面字卡切开时才用单一 `…`（U+2026），禁用英文 `...` 与 `……` 混用。竖屏切片字幕单行 10–14 字、位置上移至画面中下方安全区，避开右侧点赞评论按钮区（约 15%）与底部账号文案区（约 20–25%）。（R2-3）
- **动态字卡三规则**：字卡只干四件事（关键数字/结论句金句/对比对/章节标题卡），每微块 ≤1 张，超了就是 PPT 大字卡连放；主片 3–5 块即全片 3–5 张，切片全片 ≤2 张；字卡在屏时间 ≥ 旁白读完该句的时间 + 0.5 秒余量。字卡四件套固定（版式、入场、停留、出场每类只一种，入场 ease-out、出场 ease-in，全片不许换花样；入场默认淡入上浮，砸入只给金句/结论句，全片 ≤2 次；停留默认静止；字卡动效只动整块，逐字动画全片 ≤1 处）。字卡三数验收：大小反差（手机列表尺寸约 200px 宽一眼分清主次）、颜色（白字 + 一个强调色）、装饰（每屏 ≤2 个，只许放在文字周围）。（R84-1/2/3）
- **出处标注三层**：片内角标 + 文案来源清单 + 片尾出处卡，层层对应核查日志；角标字数 ≤12 字、停留 ≥2 秒；片尾出处卡主片片尾留 3–5 秒（经验基线）；主片三层全做，45–60 秒切片只做角标 + 文案清单。验收标准是「想查就能查到」：文案清单每个来源 30 秒内搜到原文；片内角标、文案清单、核查日志三处出处名与日期一致；每片出处卡末尾加一行「局限」；判断句不标出处。无出处的主张不许进成片，角标与口播措辞必须同级（否决项四条：无角标且文案无来源 / 角标与核查日志对不上 / 口播肯定句但角标只写 C 级转述 / AI 生成画面未标来源或许可）。（R88-1/2/3）

#### C. 节奏、卡点、转场、运镜、景别、构图：节奏是能算的数

- **节奏先算数再剪**：主片（3–5 分钟）解说段视觉变化每秒 0.5–1 次（切镜/推近/字卡/B-roll 任一都算一次），案例高潮段提到每秒 1–2 次；45–60 秒切片全程每秒 1–2 次；任何一段静态画面不得超过 4 秒。渲染后自动算「切换次数 ÷ 时长」，低于下限的段落自动标出返工；质检表新增「节奏数」一栏（切换频率 + 字数/分钟 + 静音占比三数同框），三数有一项不达标即打回。（R3-1）
- **卡点分级**：主片用软卡点 + 情绪卡点（重要点踩鼓点、次要点踩小节线；音乐情绪拐点 = 画面内容转折处），硬卡点只打爆点（切片开头 3 秒与段落转场爆点）；节拍处画面加轻微缩放跳变（100%→105%→100%）作模板默认动效。主片配乐不许全程同一情绪铺底，至少 2 处情绪拐点。（R3-2）
- **拉片进对标流程**：每周拉 1 部对标片交节奏数据（优先巫师财经 / 抖音产品君 / 心中之城）：每部记 30 个剪辑点（时间码 + 镜头长度 + 切点类型），把镜头长度画成柱状图，算出它的每秒切换次数、快段落在哪、高潮怎么处理。新片开剪前先交一张「节奏曲线草图」：哪段快、哪段慢、高潮在哪、哪里留呼吸。（R3-3）
- **转场风格规格**（主片与切片共用）：DEFAULT 硬切；TIME PASSES 溶接 0.6 秒；NEW CHAPTER 黑场过渡 0.8 秒（每章最多 1 次）或切标题卡；LIST STEPS 同方向滑入 0.3 秒（只用于清单/步骤段，全片同一方向）；FORBIDDEN 旋转、glitch、3D 立方体、呼啸变焦、随机预设；BUDGET 可见转场 ≤ 每 20 秒 1 个。审片时每个可见转场必须能一句话说出含义，说不出的当场改回硬切。（R5-1）
- **录屏跳接与章节切换按矩阵死规矩**：柱子哥式录屏教程里的跳接只许硬切 + 推近（100%→105%）或切 B-roll/录屏细节，禁短溶接「柔化」；主片换章节/换论点用黑场过渡 0.8 秒或标题卡；前后对比用擦除 0.3–0.6 秒，禁溶接；严肃/情绪段只许硬切或 1–2 秒慢溶接。（R5-2）
- **转场时长服从节奏与节拍**：60 秒切片里任何可见转场超过 0.4 秒就显慢，主片溶接不超 1.0 秒、黑场不超 1.2 秒；有配乐时溶接中点/擦除收尾落在节拍上；转场要吃掉两边素材的余量（接缝两侧各留至少转场时长一半的余帧，缺余量宁可缩短转场、不许冻帧补）；同一转场类型全片同一时长。（R5-3）
- **J-cut 与 L-cut**：先直切定节奏，再加声画错位（第一遍渲染只做直切 + 节奏数验收，节奏数不过不许加错位；第二遍在分镜表加「声画错位」列）。章节交接用 J-cut 往前拉（下一章第一句旁白或音乐层/环境音提前 0.2–0.4 秒进）；结论与情绪点用 L-cut 留住声音（旁白尾音拖 0.5–1 秒压在下一画面上）；禁旁白与字幕脱节（字幕出现时间 = 旁白出现时间，CPS≤9）；全片 J/L 密度上限：主片每微块最多 1 处，切片全片最多 1 处。验法是「感觉得到、指不出来」（重叠长度按场景分档：章节 J-cut 0.2–0.4 秒；结论 L-cut 0.5–1 秒；重大转场可到 2 秒，超过 2 秒必须能说出为什么；审片加盲听一遍）。（R128-1/2/3）
- **运镜三规则**：每个镜头先定运镜目的（揭示/跟随/强调/造紧张四选一，说不出的默认静止）；词汇表按代码参数写死（推近 scale 100%→103–105%、缓进 2–4 秒；拉远 scale 105%→100%；横摇 translate X；纵摇 translate Y；快变焦 0.3–0.5 秒内 scale 跳变，只许切片开头 3 秒与段落爆点；跟拍元素沿路径移动；手持微晃 ±1–2px，只许情绪段用一次；对焦切换只许有明确前后景分层时用、须先出小样；dolly zoom/arc 禁入）。运镜有预算与速度死数：每微块（45–100 秒）最多 2 次有意图的运镜（经验基线，短剧正式版审片时实测后定数，不进硬验收线）；推近/拉远 ≥2 秒才有沉浸感；运镜的起止落在节拍或情绪拐点上。运镜只在「画面说不清」时接手：旁白已经讲清的，镜头不许再演一遍；禁同一句旁白上同时出现运镜 + 字卡动效 + 音效三重强调。（R110-1/2/3）
- **景别三规则**：景别对照表进分镜表（七档：EWS 极远景 / WS 远景 / FS 全景 / MS 中景（默认工作景别，全片占比最高）/ MCU 中近景 / CU 特写（只给证据与情绪）/ ECU 大特写（全片最省着用，只给「就看这一处」的时刻））；景别对信息层级，不许只按好看选。景别反差是标点（重要结论前先给中景缓冲再切特写，全程同景别即打回；同一景别连续出现且无视觉变化的段落沿用 4 秒线；特写只给重要结论、反转句、关键数据；禁远景直跳大特写；同一章内至少有一次远→近的景别行程）。景别变化优先用推近/拉远，不用硬切放大（同一素材景别变化优先用推近 100%→105% 起步，硬切放大只许用在章节切换与卡点爆点；录屏从全屏切到局部先给中景过渡；推近/拉远幅度全片统一）。（R89-1/2/3）
- **构图三规则**：每张关键帧先过构图三问（焦点在三分点上吗 / 画面平衡吗 / 有没有引导线把眼睛带到焦点；居中只许对称式与直面式两种，且须在构图列写明理由，不写理由的居中一律按「没想清楚」打回）。景深分两档（浅景深档：焦点段，背景虚化或压暗，只留焦点清晰，用在数据字卡、关键结论帧；深景深档：交代段，全景、环境、录屏全清；录屏段加虚化直接否决；拉焦点全片最多 1 次，经验基线）。对比图两侧位置全片固定（左旧右新，或左前右后，定下来不许中途换边）；短剧对话场景开拍前先画线（A 在左、B 在右），越线须注明理由；仰拍/俯拍等非常规视角全片最多 1 次。（R101-1/2/3）
- **负空间三规则**：每帧先定「空」在哪（分镜表每块新增「负空间」栏：主体是什么、占画面多大、空在哪一侧、空里放什么；AI 生成帧提示词里写明留白参数；空区干净度是验收项；字幕与大字只许落在预留的空区里）。负空间按情绪分工（等待/悬念空 / 呼吸空 / 渺小/尺度空 / 压迫空；禁区：开头 3 秒禁纯空帧；「空着好看」不是理由，情绪任务一栏空着的负空间帧一律改回常规构图）。负空间有预算（主片每章 1–3 帧、切片至多 2 帧；主片每章至少 1 帧负空间帧；竖屏 9:16 的空先给字幕安全区，横屏 16:9 的空优先给大字与动态图形留位置）。（R141-1/2/3）
- **B-roll 三规则**：每句旁白先定视觉任务（分镜表加「视觉任务」列，六任务：建立/说明/证明/演示/过渡/呼吸选一，空着不许进剪；任务空着的镜头按装饰处理删）。选片过「意思五项检查」（意思/具体/语气/连续/技术与许可），禁关键词配图与陈词滥调三件套（敲键盘、倒咖啡、城市延时）；每句旁白至少比 2 个候选再定。切点与时长服从旁白，不按秒表切（切在有意义的词、想法转折或画面内动作上；简单建立画面 1–2 秒够了就走，图表与数据画面给足读的时间；切片 B-roll 密度上限每句旁白最多配 2 个画面）。（R64-1/2/3）

#### D. 声音：旁白先定，其余围着它转

- **三层混音顺序 + 电平数**：混音顺序死规矩：旁白 → 音效/环境音 → 配乐，不许先铺音乐再挤旁白。电平数（峰值 dB）：旁白 -6～-12（先定锚）；旁白段 BGM -20～-30（比旁白低 15–20 dB）；无旁白段 BGM 可抬到 -12～-18；音效 -10～-20；终混峰值 ≤-3 dB；整体响度目标 -14 LUFS（经验基线：该数为 YouTube 口径，抖音官方响度规范尚未核实，暂按此值、待核实后修正）；导出 48 kHz / 24-bit。Voicebox 克隆音处理链按顺序走：降噪 → 高通 80 Hz 以下 → 200–400 Hz 去闷 → 2–5 kHz 轻提 → 压缩 3:1（增益衰减 3–6 dB）→ 去齿音（5–8 kHz），顺序不许颠倒。（R8-1；R95-1 升级为三轨电平卡；R95-3：dBFS 管削波、LUFS 管听感，两数都得报；真峰值 ≤-1 dBTP 为文章数，与我们自己的 ≤-3 dB 冲突时沿用 ≤-3 dB）
- **Ducking 默认开 + 配乐只在情绪拐点进出**：旁白段 BGM 自动压低、无旁白段再抬回来，不许手调每一段音量；配乐进出点对齐「情绪拐点标记层」；主片至少在章节处换曲或换层，不许一首曲子从头铺到尾；45–60 秒切片只许一首曲子，但开头 3 秒与结尾 payoff 处音乐可抬。选乐铁律：有旁白只用纯音乐；重低音/失真电吉他类先排除，优先疏朗钢琴与氛围质感；授权未核实标「待授权」，不进成片。（R8-2；R95-2）
- **底层 room tone + 静音当标点 + 情绪音效预算**：每条成片底层铺一层极低的环境底噪/房间 tone，全程不断，盖住接缝；钩子句或反转句之后留 0.5–1 秒有意静音（不许用静音填没写好的过渡）；音效分两类记账：字面音效只求「几乎注意不到」，情绪音效（riser/impact/whoosh）全片有预算——切片 ≤3 次、主片每章 ≤1 次（经验基线：自拟数，短剧正式版审片时实测后定数，不进硬验收线）；R95-2 另给数：情绪音效主片 ≤3 处、切片 ≤1 处（起步量）——**两处数法未统一，待短剧正式版实测后定数**。J-cut/L-cut 进转场规矩：下个章节的声音先到 0.2–0.4 秒，或上个章节的尾音拖过去。终混交付前必须在手机外放上完整听一遍（耳机里清楚不算数）。（R8-3；R95-2）
- **三层声床模板**（R112，简写轮）：所有成片先建物理/情绪/留白三条轨道；物理层只用可追溯来源（录制或 CC0 录音库）；情绪层用低频床 + 不超过 2 个动机；留白层在口播句号后强制留 0.5 秒空档，不许用音乐盖掉。**注**：R112 的「句号后 0.5 秒」与 R8/R95 的「金句后 1 秒静音」是同一位置的两种数，原文未统一，待实测后定数。
- **配音停顿四档 + 重音预算 + 发音字典**：停顿四档写进配音执行单（句内换气 150–300ms、句间 400–500ms、金句或关键数据后 700–900ms、章节切换 1000–1500ms，作者经验基线，短剧正式版实测后定数；标点层映射：逗号=短换气、句号=句间停、破折号后拉长、省略号拖尾；一分钟内长停顿（≥700ms）超过 3 次打回重生成该句；SSML 标签层等核实 Voicebox 支持情况后再升级 v2）。重音预算：每句只标 1–2 个最重要的词，moderate 为主（八成情况），strong 只给金句与反转句；一句话重读超过 3 个词等于没重读；重音优先给动词与数字。发音字典表（词/正确读法/处理办法）：Kimi→K i m i、PPT→P P T、DeepSeek→Deep Seek、Apiiro→阿皮罗、Gemini Carbon、AArch64、libsignal；新专有名词先试读一遍再进正式生成。验听三关：5 秒测试（前 5 秒听得出是 AI 吗）、90 秒测试（听到 90 秒处有没有越听越假的累积感；60 秒以下切片只过 5 秒关）、手机外放听一遍；导出 48 kHz/24-bit WAV（Voicebox 若只给 16-bit 则取最高档并标注实际值）。（R105-1/2/3）
- **交付响度与三设备验**：终混 integrated LUFS 目标 -14（经验基线，非抖音官方要求）；真峰值 ≤-1 dBTP（文章数，与我们自己的 ≤-3 dB 冲突时沿用 ≤-3 dB）；ffmpeg loudnorm 实测；耳机、笔记本外放、手机外放各完整听一遍，手机外放必过；先测 28 条版与预览版 v3 的实测数再定交付数；走开一小时再听进审片流程。（R95-3）

#### E. 结构、视觉与动效：每个镜头要传达的信息先定，再找素材

- **调色三规则**：先校正、后调色（校正层管中性：曝光不过曝不过暗、白平衡中性、镜头间匹配以参照帧为准、色温与亮度差肉眼不可见；风格层只上品牌 look 且整片只许一系：暖琥珀 #E8A04C 或冷夜蓝 #16283F + 霓虹青 #57C7D4；校正没过不许进风格层）。颗粒分两档（矢量自绘图 4K 原生轻颗粒、1080p 放大帧重一档，两档数值写进参数卡全片固定；预设只作起点，强度从 100% 往回拉到「看得出 look、但不觉得浓」）。信示波器不信眼睛（渲染后逐帧算亮度与色温均值画曲线，超阈值帧标红返工；主色保护线：暖系琥珀不许偏橙到发烫发脏、冷系夜蓝不许发灰发绿；默认轻调色，重 look 只许封面与首帧）。（R30-1/2/3）
- **视觉叙事三规则**：每镜一视觉任务，画面先于旁白定——静音验片是硬门槛（关掉声音从头看一遍，每段能不能说出在讲哪一段，说不出来的段打回重做；画面与旁白冲突时画面赢）。七元素进分镜检查表（压缩成五项：构图 / 明暗 / 色彩 / 运动 / 节奏，每块分镜逐项打勾，缺一项写「无」不许空着；同一元素全片须一致）。母题与并置是两把刀（母题全片只定 1–2 个重复视觉元素，重复出现才算母题，出现一次叫装饰；母题须对应核查日志里的一个事实或一个转折点；并置只用擦除 0.3–0.6 秒或分屏，禁溶接糊在一起；画面拥挤时删到只剩画面任务必需的一件）。（R47-1/2/3）
- **动态图形与 SVG 三规则**：每个动效段只扛一个信息（先交 2–3 张风格帧，静态帧读不懂不许开动；风格帧定死字体与字号层级、配色、间距与网格、最小字号）。动效三原则进模板默认值（全缓动，禁线性匀速；入场错开，同一帧内多个元素入场间隔至少 3–5 帧；数据逐个揭示，每条落稳停顿 ≥0.5 秒再出下一条；屏幕字是论证本身，限定条件必须与数字同帧出现；关键数据字卡与结论句停留 ≥2 秒）。每个重要入场配一个克制音效 + 静音验动效段（全段只留一个强调点，音效电平 -10～-20 dB；动效段必须先静音看一遍，静音下看不懂说明视觉节奏没立住；竖版 9:16 重新布版，不许中心裁横版）。（R68-1/2/3）
- **数据可视化三规则**：先写数据句再画图（每处数据场景开工前先填数据句「观众应该理解的是 ____」；五级选型：一个数→大数字字卡；两个数→并排对比；多类→柱状；随时间变→折线；前后两点→两柱/斜率图；只有需要多值看规律时才上图表；全表/仪表盘/文件截图禁进正片画面；一张图一个主张，多主张拆成多个视觉节拍，每微块最多 1 张图表、切片全片最多 2 张，数量上限为经验基线）。图表即场景（每张图写清开始态与结束态，中间按旁白顺序分步揭示；悬念/结论在前的图不许提前亮终态；旁白只讲「所以呢」，不许逐字念标签与数值；时长按原文起点：一个数 2–4 秒、两值对比 3–5 秒、简单柱状 4–8 秒、简单折线 5–10 秒、多步动画 6–15 秒以上；同一资产可留到 12 秒但必须拆成 4 个约 3 秒的节拍；动效只许传达数据变化或引导注意力，禁旋转、弹跳、轴飞入、整图抖动；数字计数动画从有意义的比较值起算，不许从 0 数起）。一图一处强调色 + 诚实四查（柱状图零基线；折线图截轴须标明刻度、不夸大微小变化；百分比写清分母与百分点；预测/估算/区间数标「预测/约」；来源小字随图走；误导自测：持反方立场的人看到完整数据集，会认为这张图公平吗；AI 生成图禁做含数字的图表）。（R52-1/2/3）
- **AI 生成帧三规则**：先建角色一致性卡，再生成第一帧（描述块原文按固定顺序一次定稿：年龄/体型/肤色、脸型/眼色/眉毛/鼻子/痣疤、头发颜色长度质地与标志发型、标志服装一两件、渲染风格；参考图三张：正面/四分之三/全身；风格参考 --sref 代码/URL + --sw 值；常用参数 --ar/--raw/--s；「不许变」清单；出过好图的 seed；卡没建完不许生成该人物的第一帧；生成时提示词结构死规矩：描述块（开头，权重最高）+ 场景 + 参数，描述块逐字照贴，不许逐帧改词、换同义词；先出定妆照三视图把卡里的参考图定稿）。控制分层叠加，版本写清（描述块管关键特征与标志服装；参考图 Edit model/--oref/--cref 管脸与整体相像；--sref + --sw 管渲染风格、调色与质感；--seed 只管近似提示词的微调；禁 --sref 管脸、--seed 管跨场景；版本死规矩：生成记录写清 MJ 版本与对应入口：V6 --cref / V7 --oref / V8.x Edit model 附参考图，不许混用两套参数；验收分级：特写/近景脸与头发任一漂移即重生成；中远景只验服装与比例；风格漂移不分景别一律重生成）。一致性靠筛选（MJ 一次出图默认 4 张，每批只留最像的 1 张，其余 3 张显式标「落选（漂移项）」；选片标准写死：留的那张必须同时过三关：脸是同一个人、服装是同一套、渲染语言与 --sref 一致）。（R58-1/2/3）
- **竖屏转制三规则**：三种做法按画面内容选（单一信息焦点 → 裁切或重渲；整帧都是要点 → 贴合或竖版重排；两个相隔太远的要点 → 分屏上下叠放，各占 1080×960 一半，字幕放两格接缝处；主体移动 → 裁切窗跟着走；每块填一行「画面内容→做法→理由」，理由写不出来不许开剪）。4K 母版可裁、1080p 母版优先重渲（放大倍数上限 1.8×，文字/数字块只许重渲；Signal 4K 母版竖窗 1216×2160 缩到 1080×1920 不用放大；短剧 1080p 母版竖窗 608×1080 放大 1.8×；720p 来源竖窗放大 2.7× 禁入）。安全区 + 逐块验裁切（关键信息离底 420px、离右 200px、顶部留 ≥220px，作者估算，经验基线；固定居中裁切窗禁入；贴合是最后手段，用了要在质检单上记「贴合（原因）」）。（R75-1/2/3）
- **录屏剪辑三规则**：每个录屏动作按「上下文→动作→结果」三段剪，旁白先讲决策、再讲点击（三段缺一段不许进片；动作按「动作信封」剪：定位→靠近→点击→界面响应→确认，五步齐了才是一个视觉念头；信封外的游荡光标、找菜单、重复点、加载等待全剪掉，等待本身是证据的除外；旁白句式死规矩：每步先讲「为什么」再讲「点什么」）。缩放只为可读性，全景→聚焦→全景（缩放预算是问题不是次数：每分钟问一次「哪几处真需要放大」，答不上来的缩放一律删；放大看完一个细节必须回全景；光标只有三职：导航、指、确认；跳剪光标瞬移四修法：趁界面状态大变时切 / 切前让光标先动起来 / 光标停稳了再切 / 删掉的时间长加「时间跳过」标签；转场在录屏段默认硬切）。录前先写观众 outcome + 清屏 + 分段录，隐私专审与三速剪辑各单列一关（录前三件不许跳过：写一句「看完这段观众能做到什么」/ 清屏清单 / 按任务分段录，坏一段只重录一段；录前先录 30 秒测试段验分辨率/光标/声音/通知；隐私专审单独一遍：API key、密码、邮箱、账号 ID、账单、私聊、恢复码，处理顺序：能不录就不录 ＞ 裁掉 ＞ 遮挡 ＞ 弱模糊，弱模糊禁用于密码；节奏按认知负荷定三速：已知导航/重复动作/无意义等待＝快；核心流程/普通点击＝常速；不熟悉的设置/重要结果/要读的字/对比＝慢）。（R55-1/2/3）
- **切片再剪辑三规则**：四问纸面测试（用主片逐字稿筛候选段：①首句是否点名主体 ②有没有张力 ③payoff 是否在片尾前落定 ④去掉说话人名头还成立吗，四问缺一即否决）。专属首句按片型分（故事/演示型用结论前置、论证型用问题上屏、三种都不贴的克隆音补录一句专属开场；「所以第二点是」「正如刚才说的」等指代前文的词出现在切片首句即不合格）。中段按密度线收紧（删所有复述、删不改变含义的限定词、payoff 前的一拍停顿不许剪掉；视觉变化引用密度规格：连续 4 秒无新事件即不合格；仍超 45 秒且松的段中段加第二钩子，不许拉长，加完还松降级为重做成原创短片）。（R34-1/2/3）
- **批量出片三规则**：批量只批同构件，主片与研究关不进流水线（可批量：切片再剪辑同一主片 2–3 条、封面变体、钩子备选、选题候选、脚本草稿；不可批量：主片正片每周 1 部、研究关原子化核查、红队审稿、配音终版；批量日按认知类型分三块：高能块写钩子与选题判断 → 中能块写脚本草稿与分镜 → 低能块做渲染、导出、登记；切片变体上限是同一主片 2–3 个钩子变体）。批量日前 24–48 小时前置清单，没清单不许开工（选题候选 5–8 条筛到 3–5 条；每条钩子 3 备选已写、缺口单已填；模板与品牌 kit 锁定；渲染环境就绪）。批量产出先进候选池，不直接进发布队列；库存保持 2 周缓冲（1 部待发主片 + 4–6 条待发切片，库存低于 1 周时下个批量日提前；候选池里超过 2 周未审的切片显式标「过期复核」）。（R42-1/2/3）
- **导出与压缩三规则**：导出参数卡三档定死（Signal 主片母版 4K 24fps：35–45 Mbps → 45 Mbps，GOP 12；短剧 1080p 30fps：8 Mbps，GOP 15；竖屏切片 1080×1920 30fps：8 Mbps，GOP 15；共用行：MP4 + faststart、H.264 High Profile、yuv420p、连续 2 个 B 帧、CABAC、VBR、AAC-LC 48 kHz 384 kbps 立体声、BT.709 三标签；帧率死规矩：24 不许变 30、30 不许变 24，23.976≠24、29.97≠30；CRF 16 是近似值，导出后用 ffprobe 验实际码率落在区间内）。母版与上传件分开（母版 = lemo-opuscar 渲染出的无声 MP4 + mix.wav + 合流后高码率版；上传件 = 按参数卡压出的 MP4，文件名加 `-upload` 后缀；不许把上传件当母版归档，不许把 1080p 放大成 4K 上传）。导出前 90 秒预检单九项（分辨率与源一致 / 帧率与渲染一致 / 码率在参数卡区间内 / ffprobe 实测 / MP4 + faststart / 音频 48 kHz AAC-LC 立体声 384 kbps / 色彩 BT.709 三标签齐全 / 响度 −14 LUFS、真峰值 ≤−3 dB / 回放一遍导出文件本身 / 母版与上传件分开归档），九项有一项不过即打回重导出。（R117-1/2/3）
- **预告片与先导片三规则**：先导片是「三幕微缩」，不是主片「浓缩摘要」（15–30 秒先导片按三幕压缩：铺垫约 5 秒 / 转折约 8 秒 / 高潮蒙太奇 + button 约 7 秒；开剪前先写 spine 两行：一句话前提 + 一句情绪；先导片只开主环、不闭环：主片的结论句、反事实句、闭环答案一律不许进先导片；先导片发布时间为主片前 24–48 小时发，经验基线，不许与主片同一天发）。音乐先行、画面后贴（先选一首有清晰三段起伏的曲子，标出 hits 与 drops 再贴画面；先剪广播版，只验三件：钩子句听得清、音乐三段分得清、静音处听得出停顿；镜头逐幕缩短：铺垫 2–4 秒/镜、转折 1–2 秒/镜、高潮蒙太奇 0.5–1 秒/镜；最后一击前留 2 秒静音）。素材先「打散入库」再拼（主片交付时同步 log 全片，每句金句、每帧强画面单独编号，按「钩子句/世界观镜头/情绪点/数据爆点」四类入池；先导片只从池子里取；字卡 ≤3 张、每张 ≤5 词；button 一句：笑点/反转/一句金句三选一，button 后只跟标题卡 + 发布时间；开剪前先拼六格 beat 板）。（R121-1/2/3）
- **代码化剪辑三规则**：模板只装「洞」不装内容（文案、数字、图片 URL、时长、颜色全是 props；品牌参数只许存在于一个共享配置里，场景文件出现内联色值即标红；props 扁平无聊；渲染前过 props 校验：缺字段、超长、URL 不可达三项有一项不过即不渲染；输出文件按行键命名：片名-集数-版本号）。开写组合前先定五个决策（帧率/时长模型 / 溢出策略 / 宽高比策略 / 资产确定性 / 音频来源；五项有一项没定不许写组合；渲染只出无声 MP4，旁白/BGM/音效一律渲染后由 mix.py + ffmpeg 合流，不许在组合里排音频时序）。代码渲染出的是原材料不是交付物（每批渲染先拼 contact sheet 看一遍，再对母版走终检三遍；字幕对照真实波形核对；模板准入门槛：一个形状重复 ≥3 次才配建模板）。（R39-1/2/3）
- **分镜表三规则**：分镜表一格一任务（每格七栏固定：编号/时间码/旁白句原句照抄/画面任务一句话/景别 + 运镜写可执行的数/画面来源五选一/素材许可状态，缺一栏不许进渲染；画面任务写不出来的格删格或并进上一格；分镜表是脚本锁死后才画的执行件，旁白句一格一字不改）。相邻两格必须换一样（景别、角度、画面类型三项中至少换一项；机制讲解段也不例外；每格时长写死在时间码里，静态画面不得超过 4 秒）。编号即合同（主片按「章-格」编如 S2-07、切片按「C-格」编；编号一旦写进分镜表 v1，就与三处绑定：渲染输出文件名、素材登记卡的格号、逐句审片的定位句；改格只改内容不改编号；同一版本内编号终身不变，整章重排、格数大变时升版本号 v1→v2，旧编号随旧版封存、不许在新版里复用旧号；删格不重排——被删的格在表里标「作废（日期 + 原因）」；故事板编号带「SB-」前缀，正式资产编号带「REF-」前缀，两套号不许混进同一张表，拼版总览图不进资产台账）。（R137-1/2/3）
- **分镜表新增列总清单**（全天内先后新增，合并为当前版列清单；收敛点是 R137 的七栏模板，其余列按需挂在七栏之下，不另立新表）：构图列（R101）、运镜列（R110）、声画错位列（R128）、负空间列（R141）、画面性质列（实拍/档案/示意/AI 生成/自绘示意图）+ 接缝因果行（R125）、接缝关系列（R116）、时间结构列（R106）、分享时刻列（R120）、记忆挂钩列（R142）、TEMP 标记列（R130）、标识行（R133）、回来的理由栏（R108）、合集引导句栏（R114）、视觉任务列（R64）、转制列（R75）、景别列（R89）、出处角标列（R88）、新组块/取回点列（R81）、人物关键点列（R22）、块末钩列（R29）、幕/节拍列（R86）、收法列（R79）、反方位时间码标记（R127）、动效段标记 + 揭示顺序列（R68）、数据句列（R52）、字卡列（R84）、画面任务列（R47）、母题列（R47）、脊柱栏 + 转折点列（R45）、参照帧列（R30）、L3 栏（R6，载体改为动态图形/字卡/作者补充评论）、转场列（R5）、开环/闭环列（R11）、节奏曲线页 + 五检查点行（R3/R18）、微块结构表（块号/时间/小钩子/内容/小满足/过渡句/能量，R18）、音乐进出列（R8）、静音标记（R8）。

#### F. 素材管理：找得到、打得开

- **每条片子一个文件夹、固定五格**：01_原始（录屏、AI 生成图/帧、参考音、已授权素材原文件）/ 02_配音（克隆音 wav、mix.wav、处理链记录）/ 03_工程（渲染代码、分镜表、制作规格单、核查日志）/ 04_图形与音乐（矢量自绘图、BGM、音效、封面图）/ 05_成片（母版、竖屏切片、轻量版）。不按文件类型设全局文件夹；命名：`YYYYMMDD_片名_内容_vN`，禁空格与 & ? # " ' /，序列补零，版本号写进文件名、不靠修改日期认版本；文件夹里一份 README（写清本片缩写、五格里各放了什么、母版版本号）。下一条开剪的片子（Signal 主片）起用新形态，旧片子不翻旧账。（R26-1）

### ④ 运营站

#### A. 定位、选题与排期：先判方向，再排档期

- **定位三圈楔子校验**：真实干过 / 真反方观点 / 有需求——三圈缺一不许立定位；定位句模板「我帮［具体观众］做到［具体结果］，不用［常见痛苦］」；定位句三关检验（具体的人名/场景替掉「普通人」；具体的交付物替掉「学会 AI」；反方句能激起争论）；定位句是「主片 3–5 分钟」的上限边界：超出边界的选题（人物/社会/历史）进切片验证，不许直接进主片。（R40-1）
- **每季度先写 12 条标题**：选题会前先写 12 条标题（4 条「具体怎么做」+ 4 条反方判断 + 4 条实验型），写不出 12 条标题的定位不许立；每季度盘一次，盘点时先问「12 条标题里有多少已经拍了，拍了的有没有低于基线的」。定位是「每季度的标题清单」。（R40-2）
- **前 20 条主片是学费**：前 20 条主片是验证定位的学费，满 20 条才做第一次定位复评；20 条前只调执行层（钩子、标题、节奏），不许动定位句；20 条后复评看三数（平均观看占比 vs 同格式最近 10–20 条中位数 / 完播率 / 单条涨粉，连续 3 条同类低于基线才查共因）。（R40-3）
- **选题三级库**：D 库升级为三级选题库（核心主题 ≤5 个收纳架 / 子话题 / 单篇切口，每条切口只答一个具体问题；密度分级：高密度进主片、轻型进切片；红灰榜：红榜＝已验证高于同格式近 10–20 条中位数，灰榜＝待观察；每周复盘滚一次，月末大滚一次清三个月未动的死库）。热点是触发器：先匹配库存，再过四问（发生了什么 / 我认为意味着什么 / 给谁看 / 看完能干什么或懂什么），跳过条件任一即跳；精简版研究关；热点响应默认只做 45–60 秒切片当天发或 X 帖；主片不许为追热点插队；热点与主片档期撞了先报用户、不许 cron 擅自改档。热点片 24–72h 内更新 + 转常青进红榜；三个结构微调信号进每周复盘（连续 3 条同类选题平均观看占比低于同格式近 10–20 条中位数 / 某子话题下可写的切口用光了 / 同一问题在评论区出现 ≥3 次）。（R24-1/2/3）
- **热点日历与选题排期三件分开记**：选题库（D 库只囤题目、不排期）/ 脚本库（写稿流水线半成品区）/ 日历（哪天发哪条的出货单）；排期动作是「从库里抽」，不是「现想题目」；日历固定骨架：每周 1 部主片 + 2–3 条切片。加伊莎四格 + 配比 + 弹性格（机制格 / 实证格 / 工作室日常格 / 关注·复访格；配比经验基线：两周一个循环——主片 2 条、切片 4–6 条、关注格 1 条；弹性格每周 1 格约 20%；热点只走弹性格，主线各条顺延一个位置；选题保质期：时效题最多提前两周排，常青题可提前一个月）。排期五步压缩版 + 维护规矩（盘点半小时 / 抽题一小时 / 落位半小时 / 留弹性：切片格临近排期 48 小时做不出来自动启用弹性格顶上，原条顺延；主片格提前一周预警、顺延整周 / 归拢制作日；维护三条：周日半小时微调下周 / 忙不过来降频率、不降格 / 断档用图文兜底）。（R122-1/2/3）
- **发布节奏与时段**：时段是「起步候选」，不是验收线（默认时段沿用已定的固定日 + 21:00；测试窗口只开在切片上：工作日 12:30 与工作日 18:00，各连跑 3 条切片再判；主片时段不参与测试；粉丝活跃时段页面 1000 粉才解锁，解锁后进创作者中心亲眼核一次峰值、再替换测试窗口）。频率服从产能与质量（每周 1 部主片 + 2–3 条切片已落在 Buffer 的 2–5 条区间，不为凑数加更；切片只从主片提炼，不许为填发布日历单独赶一条切片）。发布日历提前一周定死 + 同龄对比（每周复盘时定死下周发布日历，定死后只许用户改；复盘时所有片子按同一龄期比，72h 节点是主判据；时段测试跑满两周、每窗口 ≥3 条再判，窗口之间差不到 10% 即判「无差异」，回默认时段）。（R28-1/2/3）
- **冷启动期三规则**：验收单位是「测试条数」不是「天数」（切片 20 条判切片方向，主片 6 部判主片方向，两条线分开判；每条只记三数：72h 平均观看占比、完播率、单条涨粉数）。发布前过「两理由」自查（被推荐的理由 + 被关注的理由，缺一个不许发；被推荐的理由写进投稿文案第一行，被关注的理由写进片尾）。先过资格检查再谈内容（原创、无他站水印、信息量配得上时长；判定窗口 24h / 72h / 7d；72h 节点是主判据）。（R70-1/2/3）
- **系列化三规则**：系列先填「系列卡」（六栏：系列名 / 形式五选一 / 集数与终点 / 弧线五段 / 每集一句话 / 单集自成一体标准；母话题下至少能列出 5 个不重复的子话题；第一集发布前至少拍好一半集数：迷你系列 3 集先拍好 2 集再发第 1 集）。每集三件套（单集闭环 + 集间钩 + 固定识别；标题格式「系列名 | 第 X 集：具体话题」；片头 1 秒系列视觉标识；关注理由写具体不写口号：片尾只许「下一集讲 X，想看的点关注/进合集」；系列内集与集之间不许断超过 1 个发布周期 1 周）。系列按「集群」验收（集间续看率 / 系列涨粉 72h 节点 / 合集完成率；至少跑满 6 集再判，头两集数据差不判死刑；烂尾记一次交付事故）。（R20-1/2/3）
- **合集运营三规则**：合集与系列分两张表（合集是收纳目录页，系列是弧线；一个合集只装一类内容；选片四维打分：画面清晰稳定 / 内容有记忆点 / 剪辑节奏舒服 / 配乐贴合情绪；两个分类合集尚未建，2026-11-12 10:27 待办：暂缓，本轮只交建卡、不擅自建）。合集的入口在片尾与主页（片尾口播带内容 / 文案写清合集名 + 本条是第几条 + 合集里还有什么 / 评论区作者补充评论一句合集引导；封面竖版、主体突出、色调统一）。合集按集群验收（合集完成率与续看率是主指标，集间续看率健康曲线参考第 2 集 60–70%、第 3 集 45–55% 之后走平，经验基线；合集内单条对照自家同格式基线；总播放量只作规模参考；系列合集未拍满一半不许在片尾预告下一集；合集内作品顺序按弧线/叙事顺序排，不许按播放量重排）。待核实：合集创建门槛（617 粉够不够）、合集页连播机制。（R114-1/2/3）

#### B. 分发、搜索与标签：每条主片拆成原子再发

- **分发只分「原子」不分「原样」**：每条主片先拆 5–8 个原子（原子七类：钩子句 / 机制点 / 证据点 / 对比对 / 金句 / 场景 / 数据点）；每原子四项验收（独立成篇 / 有 payoff / 不依赖前文 / 有独立标题）；同一原子跨平台错开发布（不同平台不同日；同一平台内同一原子至少间隔 3 天；一源原子 1–3 周内发完）。旧原子 3–6 个月后才许回收（三条件 + 刷新四件：换钩子 / 换画面 / 换数据 / 换结论句）。（R46-1/2/3）
- **一源三发，分层改**：母版只做一次，平台差异只改四件（画幅 / 时长 / 钩子句 / 文案 + 封面；禁横屏母版直接竖屏照发、带其他平台水印跨平台发；X 视频 ≤2 分 20 秒，原文数，待核实）。错峰发布 + 分平台算基线（同一主片衍生件错开 1–2 天发；三平台数据各算各的，禁拼「总播放量」）。三平台红线分开记（抖音 5.1 禁自动程序、AI 声明、置顶评论 2024-10 已下线、粉丝活跃时段 1000 粉才解锁；小红书口径须进 App 亲眼核实）。（R67-1/2/3）
- **抖音搜索优化三规则**：关键词清单四类 + 每条只答一个搜索问题（品牌/账号词、品类/需求词、问题词、对比/决策词；清单先立 20–30 个，每类 5–8 个，跑满一个季度再扩）。搜索友好内容四处植入（标题、口播、字幕、评论区问答，同一词四处同现，但不许堆砌；标题主关键词放前 10 个字内；口播前 3 秒出现主关键词；话题标签 2–3 个；标题可读性与判断优先于关键词前置）。搜索流量按周复盘（搜索流量占比 + 展现词 + 点击词三数；搜索占比涨了、但平均观看占比跌了，判负）。（R87-1/2/3）
- **话题与标签运营三规则**：标签先过三对齐（口播词 / 字幕与画面文字 / 文案三处出现同一组核心词；标签三类：主题 / 意图 / 系列·品牌；默认 3–5 个；禁 #fyp 类泛标签、禁标签墙超 5 个、禁蹭热无关标签、禁同一组标签原样贴每条；用前点进标签页验顶部 5 条是否同类）。固定 2 + 轮换 1–3，10–15 条后复盘（固定 1 个主题锚 + 1 个系列/品牌；胜者留、败者汰，连续 3 条低于基线且只差在标签的先换标签再疑内容）。平台话题/挑战参与三问（库里有没有 / 角度是不是我们的 / 人群对不对，一问不过即不参加；每条最多 1 个热点话题标签）。（R92-1/2/3）
- **投稿文案五段式**：第一行只写对象 + 收益；其余四段各一行：好奇句 / 搜索词 / 一个 CTA / 可信度；主片 3–5 行，切片只留 2 行。文案与标题、封面、首帧四件各干各的活（不许复述标题原话、封面大字、首帧钩子；CTA 评论/收藏/关注/进合集四选一，禁四连喊、禁外链与私域引导）。文案一次只测一个变量（验收看评论 + 收藏 + 主页访问三数，与同格式近 10–20 条中位数比；两周一循环，每轮测 1 个变量、连测 3 条）。（R62-1/2/3）
- **矩阵运营三规则**：分工卡先行——副号开号前先填「矩阵分工卡」，无卡不开号（六栏：账号 / 人群 / 选题方向 / 内容形式 / 发布节奏 / 与主号的边界；加伊莎主号：AI/科技深度主片 3–5 分钟、每周 1 部，已定不动；明有期副号：方向待用户终确，暂定「26岁｜对未来保持好奇的普通人」，简介与昵称待确认，方向未终确前不许发第一条；同一选题两号各讲一遍时，必须换表述与素材，原样搬运判内耗、当场打回；数量上限按人力倒推：目前 2 个号，不许为「矩阵」再开第三个号；副号节奏服从主片节奏，不许为矩阵加更）。错峰发 + 每周内耗检查（同一账号每天 ≤1–2 条，经验基线；不同账号同一主题错开 30 分钟以上，且不许两号同一分钟发同一主题；同一条内容在不同平台的发布时间拉开 2 小时以上；每周复盘加「内耗检查」两问：同一天两号视频是否人群重合高、推荐量互相压制 / 同一关键词下是否多个自家账号同时出现在前列，任一答「是」即判分工失效，先重划人群与选题边界；副号冷启动前 3 条：同一定位、不带联系方式；视觉统一但简介不完全相同）。账号台账一表管住 + 效率只压搬运、不碰自动发布（台账列：平台 / 账号 / 绑定手机 / 责任人 / 授权到期 / 简介版本 / 前 3 条定调状态 / 最近发布日期；效率指标：从成片到两号都发完，中间人工搬运动作数；压搬运的办法是模板化，不许用矩阵 SaaS 自动发布，5.1 红线；每条发完在台账上记一次）。（R148-1/2/3）

#### C. 数据复盘：按观众顺序读数，只改一杠杆

- **数据复盘法五步**：按观众顺序读数（点开 → 留存 → 占比 → 来源 → 留下）；每周 20 分钟五步复盘法（定三件事：一角度重复 / 一习惯戒掉 / 下周选题进 D 库）；单条弱片不是判决（连续 3 条同类低于基线才查共因；数据未满 72h 不下结论）。（R35-1/2/3）
- **留存诊断表**：形状 → 杠杆（前 3 秒悬崖 → 钩子；第 4 秒起缓慢流失 → 节奏；某一点断崖 → 那一秒的节奏/切口/台词；末段 20% 跌落 → 结尾；中段隆起 → 重看点）。基线用自家最近 10–20 条同类作品的中位数，外部数字不进验收线（文中 50–70% 只是经验参考值）；一次只改一杠杆，同一改动连测 3–5 条再判定（留存测试日志）；24h 只作预警，判定一律用 72h/7d 同龄数据。（R4-1/2/3）
- **流量来源拆解三规则**：流量来源五分法进复盘表（每条主片 72h 记五数：推荐 / 关注 / 搜索 / 个人主页 / 同城与其它，五数之和 100%，缺一项不许填表；每数的诊断含义先定死；同一条片子的五数必须与同格式最近 10–20 条的中位数逐项对照）。搜索占比连续 3 条高于同格式中位且呈上升，才立系列（单条搜索占比高只记「观察」，不立项；立系列后复核两件事：标题是否系统性地踩中了搜索词；系列第二条的搜索占比有没有接住第一条）。播放量掉了先看来源结构再定动作；看数纪律（每天只看一次、每次 10 分钟；每周日 30 分钟复盘五栏：本周播放最高 / 完播最高 / 流量来源亮点 / 涨粉最多时段 / 下周必改 1–3 项，改动超过 3 项等于没列）。（R135-1/2/3）
- **六频道墙**：同体量 2 家（约 500–1500 粉）+ 高一档 2 家（3–10 倍）+ 上升期 2 家，另可 1 个邻站名额；每家每周最高 2 + 普通 2 + 低 1 条，低样本记扑因；每周 60 分钟六步 + 五行日志；月度三问 + 「缺席」行优先进选题库。（R31-1/2/3）
- **账号健康自查三规则**：流量掉了先分三类再动手（内容 / 账号 / 大盘；判定顺序：创作者中心 → 自家基线 → 2–3 个对标账号同期数据；五个慌动作禁入：狂删视频、疯狂补发冲喜、买粉刷量、频繁改资料、没查清原因盲目申诉）。原创度四维自查进发布前检查（画面 / 文案 / 音频 / 行为；同一模板连续用满 3 条即换版式；AI 生成内容发布时必须勾「内容由 AI 生成」声明）。申诉四步（查 / 定 / 申 / 等）；恢复天数只作记录、不承诺，恢复判定以数据回到自家基线为准。（R78-1/2/3）
- **粉丝画像三规则**：画像两套分开记（创作者中心粉丝画像验存量与巨量算数关键词画像验增量是两套数据、两个口径，不许混成一个数；先写清目标人群三特征：年龄段 / 性别 / 地域或兴趣，最多选三个，须与「26 岁普通人视角的科技观察者」定位对得上）。TGI 与占比双读（读画像先同时写两个数：该特征占比 + TGI；信号判断表四行：TGI 高、占比也高 = 人群匹配；TGI 高但占比低 = 疑似小众偏好，先标「疑似」，须满足 4 周窗口 + 连续三周同向才可立；TGI 低但占比高 = 大盘人群；性别/年龄与预期完全相反 = 词义偏差或需求错位）。小样本陷阱处理 + 画像只用来排除，不用来预测（总粉丝 617，画像结论一律按小样本陷阱处理——时间窗至少 4 周，单周画像不许下结论；看趋势不看单点，同一特征连续三周同向才认；画像只用来排除，不许写「画像显示这条会涨粉/会爆」）。（R119-1/2/3）

#### D. 收藏、复访与转化：播放量不是终点，回来才是

- **收藏与复访三规则**：收藏分内容类型验收（只有工具型内容：步骤型 / 清单型 / 判断型，才进收藏验收线；收藏率 = 收藏数 ÷ 播放量，与同类型最近 20 条中位数比）。收藏四位置进发布前自查（前 3 秒报用途 / 中段留一屏可截走的信息 / 结尾给具体回看触发点 / 单条结尾报合集编号，缺一项不许发；禁「记得收藏」式空口号）。合集是收藏的放大器（合集与系列分两张表；合集数据先记原始两数：合集进入数与合集内续看数；合集完成率口径待核实前不写、不算、不进验收线）。（R82-1/2/3）
- **播放→关注的转化链三规则**：转化漏斗分三段记（播放量 → 72h 涨粉 → 涨粉率 = 72h 涨粉 ÷ 播放量，每条片子 72h 节点记一次；诊断对照表；涨粉率目标不许拍数，先跑满 10 条同格式片子取涨粉率中位数当自家基线）。每条片子结尾必须留一个具体的「回来的理由」（下一集的具体话题 / 固定栏目的下次时间 / 这条的方法还能用在哪，三选一；禁「记得关注我」空口号、禁临时编的下一集）。主页 2 秒扫描验收（简介一眼看懂价值 / 置顶 1 条代表作 / 最近 3 条封面与话题一致可预测；断更超 1 周主页即判「不可靠」；617 → 1000 还差 383 粉，差数只记、不许写「预计 X 周涨到」）。病例：《独处》110.6 万播放、Claude 封号图文 10.3 万播放，总粉丝却只有 617——分发跑通了、转化没跑通。（R108-1/2/3）

#### E. 评论区、粉丝分层与私信：48 小时维护单，人亲自回

- **评论区运营三规则**：置顶已死（抖音评论置顶功能已于 2024 年 10 月下线，2025 年 7 月官方对媒体确认，据正观新闻 2025-07-28 报道转述，B 级证据；建议下次进创作者中心/App 再亲眼核一次；第 6 轮规则 2「L3 进置顶评论」作废，改为 L3 进动态图形/字卡/作者补充评论）。发布后 48 小时维护时间轴 + 回复三细节（0–30 分钟回前 5 条、给 2–3 条点赞；30 分钟–2 小时回提问和反对；2–24 小时每 2–3 小时扫一次；24–48 小时把高赞提问记下来；每条带一个新信息、末尾再抛一个小问题、优先回提问和反对；同一问题被问三次 → 记进选题库、做一条视频；Muse 批量起草回复，用户在 App 里手动粘贴发送）。评论区三类原话进选题库（高赞提问 / 反复出现的反对 / 同类追问；下一条开头第一句点名回答「上条有人问……」；红线：不留微信号、不引导加群、不贴外链；反对意见不删；评论少先看播放量）。（R14-1/2/3）
- **粉丝分层运营三规则**：三层按最近互动时间 + 累计互动贡献定，每月 1 号重算（核心层：近 30 天评论或转发 ≥2 次，或近 90 天评论 ≥3 次；活跃层：近 90 天有点赞/评论/收藏任一、未达核心线；沉睡层：关注后 90 天零互动，或只点过一次赞再无动静）。每层动作不同（核心层用户本人亲自回、每条主片发布后 30 分钟内先回核心层评论、每月 1 次平台内专属动作；活跃层每条结尾留一个主问题、评论区 48 小时维护单优先回提问与反对；沉睡层只做内容唤醒，每月 1 条「回头客向」内容，禁批量私信、禁自动化触达）。转化只看升层率，不看总粉丝数（每月记三数：核心层人数、活跃层 → 核心层升层人数、沉睡层被唤醒人数；先跑 2 个月攒基线再定目标；沉睡层连续 3 个月零互动标「长期沉睡」）。（R97-1/2/3）
- **私信与粉丝群运营三规则**：三层人分开服务，复购层改成「深度层」（围观层要内容预告与系列钩子；熟客层要点名回答；深度层要未公开资料、提前看片、选题投票权；群没建之前三层服务先在评论区 + 私信里分流做）。群是留人不是拉人——建群触发条件是熟客层人数，不是总粉数（两条同时满足才建：评论区常互动的熟面孔 ≥20 人，连续 4 周、每周至少 3 位不同熟客留言 + 连续 3 条主片精选候选达标；主页展示粉丝群面向万粉主播、直播间入口须开直播，两条路现在都不通，当前唯一承接是私信 + 评论区；门槛预定粉丝团 1 级试两周，经验基线）。一周四条日历 + 三条换一条 + 私信「只回不主动推」（周一主片预告、周三答疑或征集、周五最值得收藏的一条方法/资料、周日幕后/制作过程；三条让别人有收获的内容换一条求关注/求收藏/求进群；主动私信只发回复提问与选题投票/入群邀请两类，发送永远归用户手动）。（R103-1/2/3）
- **粉丝分层两套名字合并说明**：R97 的「核心层 / 活跃层 / 沉睡层」与 R103 的「围观层 / 熟客层 / 深度层」是同一批人的两套名字，须合并为一张表：核心层 ≈ 深度层（高互动）、活跃层 ≈ 熟客层（中互动）、沉睡层 ≈ 围观层（低互动/只看不互动）。统一口径待用户拍板前，复盘表上两列并记、不许混成一个数。

#### F. 变现、DOU+ 与风控：先跑通自然数据，再谈花钱

- **变现路径三规则**：变现分两本账（租来的 / 自有的；租来的：星图、DOU+、平台补贴，规则随时变；自有的：私域、产品、会员，规则自己定）。四步顺序（免费引流品 → 小付费产品 → 高价 offer → 每单卖更多；验收用引流品领取率与小产品转化率，先跑 3 条再定价）。星图价不许拿头部价当目标（Michael 大麦哥 700 万粉，植入 10 万 / 定制 12 万一条是对标价，不是目标价；报价先按自家粉丝数与涨粉率中位数算）。（R44-1/2/3）
- **DOU+ 三规则**：投前三问（只投自然数据已跑通的片子，三指标满足两条才列入候选：平均观看占比高于同格式最近 10–20 条作品的中位数 / 评论区有真实提问 / 72h 节点涨粉或主页访问高于平时同格式 72h 基线；一条都不满足的片子先改前 3 秒与钩子，不许拿钱补内容；目标只开两档：粉丝增长 617 → 1000 冷启动期与点赞评论测内容方向，主页访问目标不许选）。小额多批 + 单条封顶 + 止损线（首测从最近 3 条自然数据最好的主片/切片里挑，每条 50–100 元，定向交给系统自动匹配，兴趣标签最多 3 个；第二批只留成本最低的那条集中追加；单条累计不超过 300 元，经验基线；止损线：投放后 72h 节点平均观看占比未高于基线、或单个粉丝成本高于首测三条最低值的 1.5 倍，立即停；预算决策权在用户：首测预算 3 条 × 50–100 元 = 150–300 元，须用户拍板后才投）。投后复盘只看三数，不看播放量（互动成本是否低于历史均值 / 单个粉丝成本是否可接受 / 72h 涨粉是否高于平时同格式 72h 基线；三数里两条不过即判负；首测三条互相比较取最低成本者，成本基线由首测建立；投放数据与自然数据分两行记）。（R129-1/2/3）
- **自动化运营的边界与风控三规则**：风控三因素自查（环境 / 内容 / 行为；环境：账号登录 IP 是否稳定、设备是否固定；内容：是否原创、有无搬运嫌疑；行为：发布频率、互动频率是否像人）。环境隔离（一号一配置文件一出口 IP；抖音创作者中心只从用户家里 IP、他自己的浏览器登录；X Loui 走 X 链式 v2 + LinkStatic 纽约静态住宅 IP 64.50.132.248，每次运营前先验出口 IP 与 WebRTC）。行为节奏须像人（Loui 每天不超过 3 条；限流/异常信号出现一次即停全部自动化动作；抖音侧不做自动发布、不做自动互动、不做养号，5.1 红线）。（R49-1/2/3）

### ⑤ 把关站

#### A. 红队式审稿：事实红队、逻辑红队、审美红队，三票不过不许开拍

- **红队式审稿法（R10，原文未给「三规则」拆分，照录五维 + 三招 + 三级）**：审稿五维（判断 / 事实 / 逻辑 / 节奏 / 整体感）；新鲜眼睛三招（冷却至少隔 2 小时、隔夜最优 / 换角色 / 朗读）；反馈三级（否决 / 重伤 / 轻伤）；同一类否决在两篇稿里重复出现即升为写稿规则；仲裁标准前置（事实 ＞ 判断 ＞ 节奏 ＞ 审美）。
- **红队审稿卡三票（R93，简写轮）**：三分钟否决票（事实红队必过四问：口径是谁说的、哪版原稿、第几版；图号/时戳/链接是否可点；反方有无写进稿；版本号/日期是否标清；任一项答不出即停笔）。七分钟逻辑红队（每段关键结论配一句反向测试句，没有就降级措辞为「据 XX 称」或删）。十分钟审美红队（切片 ≥14 条字幕/分钟且单条 ≤18 字；静音/空画面 ≤4 秒/段；主片 ≥8 个视觉事件/分钟；不达标直接回写稿站）。产物：红队审稿卡模板（否决票 / 降级票 / 放行票三栏）。
- **自我审稿的盲点四招**：盲点先标名（审稿结论默认降级）；破坏性审稿四招（改呈现 / 换通道 / 倒着读 / 遮着读）；冷却与新鲜眼睛是硬性前置（日常至少隔 2 小时；正式版前必须隔夜或由用户本人审阅；赶片四招全上、结论标「未冷却」、只记轻伤不记否决）。（R54-1/2/3）

#### B. 交付质检：终检三遍、逐句审片、白队五遍、返工单闭环

- **交付质检与逐句审片（R23）**：质检四遍按顺序走（文件数 → 画面 → 声音 → 文字；文件数不过直接打回重导出；红队在前、质检在后；质检发现的是文件问题，不许在质检环节重写稿子）。逐句审是质检的第三与第四遍（每句核三件事：画面对不对 / 字幕对不对 / 声音对不对；切口黑帧/闪帧只能逐帧步进查；首帧与尾帧必查）。每个交付版本单独过一遍（母版、竖屏切片、轻量版各自独立导出、各自过一遍；交付日问题分两级：立即修——破规格或破信任；先报用户——其余小问题，由他定）。
- **终检三遍单（R36）**：终检三遍（常速通看 → 逐句审 → 闭眼听，顺序不许乱；闭眼听须查 stderr 的 OOV 记录）。结构性缺陷只许返工（生成帧错 / 事实错 / 授权未核实）。终检只认导出文件（放行记录四项：审片人 + 版本号 + 导出文件名 + 溯源包）。
- **白队五遍法（R107）**：白队五遍法（每遍只查一类错：文字遍 / 画面遍 / 声音遍 / 技术遍 / 交接遍；白队只改事实性错误，结构/判断/节奏问题一律退回红队单）。三分类进白队单（硬性平台规则一票否决 / 平台推荐参数不达标记「待优化」不否决 / 团队自定标准；抖音侧硬性数值待核实前写「待核实」）。验成片只验导出的文件，不验时间线（导出后必须在独立播放器里从第一秒播到最后一帧；静音完整看一遍；手机外放完整听一遍；三项缺一项白队单不许签字）。文件命名规范：`片名_比例_平台_版本_日期.mp4`，禁 `final_final.mp4`、`export_v1.mp4`。
- **返工单五要素 + 闭环（R139）**：返工单一问题一行，五要素缺一不可（版本 / 时间码时:分:秒:帧，注明帧率 / 现象实际是什么 / 应有应该是什么 / 等级；现象与应有必须分开写，只写感受不许进单；持续性问题标区间不标单点；没有时间码的意见当场退回重写）。QC 与审片分开跑（审片单管故事、节奏、判断、整体感；返工单只管画面/声音/屏上文字/文件四区；QC 时机三处：素材进来时抽查 / 每次给用户看之前短查一遍 / 正式版交付前按规格全查，每种格式单独过；最后一遍 QC 由没剪这条片子的人做——单人工作室用第 10 轮口径：冷却 2 小时以上，赶片时换角色 + 大声读屏上文字；机器先行：响度/峰值/静音/黑帧/冻帧先过自动检测，人只判四件机器判不了的：音画同步 / 镜头间色彩 / 名字与标题 / 黑·静·冻是不是故意的）。返工单闭环（等级三级：否决必改；必改改或写明不改的理由、由用户拍板；可放行批量记、不阻塞发布；修完后只复核改动处与相邻切口，再完整播一遍；新版重新编号，返工单随版本号走；故意留下的差异写清三行：留下了什么 / 谁同意的 / 为什么）。
- **交片判定单（R115）**：交片标准前置（开剪前写死本条的「完成定义」三行：本条的判断句 / 必须讲清的机制点 / 结尾的 payoff；通用项不许抄进完成定义充数；交片判定只看两档：红队三级里「否决」清零是硬门槛，「重伤」改掉或写明不改的理由、由用户拍板，「轻伤」不拦交片、记进「下条改进清单」）。三个停手信号，出现一个即停手（改回头 / 只变不一样 / 三遍无停：完整看三遍、一次都没停下来想改；主片约 9–15 分钟，切片约 3 分钟内）。截止时间是唯一的防无限精修手段（每条片子开剪前定死交片时间；到期时否决未清零——不发，改期并记一次「延期」；只有轻伤/已拍板的重伤未修——照发，轻伤逐条记进「下条改进清单」）。
- **陌生人测试单（R98）**：陌生人测试是正式版前置验收件（主片正式版前必须交一张陌生人测试单；切片每批抽 1 条测；测试人 = 1–2 个真陌生人 + 用户本人按陌生人协议重看：隔夜冷却后，不暂停、不改、不记笔记，看前不许翻脚本与分镜表；缺一档标「半测」）。先通看、后问卷（请人前先做「抛光通看」；放给测试人看全程不暂停、不解释、不插话、不剧透；基础五问先问：能一句话说出讲了什么吗 / 哪里走神了、第几秒 / 哪里没看懂 / 哪个数/哪句话记得最清 / 还想继续看下一条吗；项目专问后问，只问自己担心的 1–2 处；测试人只给感受与理解、不给改法）。模糊意见翻译表 + 两条过滤器（「有点无聊」→ 先查节奏再查 stakes；「没看懂」→ 先回脚本查机制再回画面查；「开头没抓住我」→ 回第 1 轮片头三件套与第 11 轮缺口单；过滤器：本能 + 重复——两个人以上在同一处走神/没看懂/没被抓住即判「必须修」）。
- **画面与旁白的匹配度审片（R125）**：逐句审片时每句旁白配一张关键静帧，顺带过「画面—旁白匹配三问」（这帧画面是「这件事本身的画面」，还是「这类事的示意画面」/ 画面里的时间/地点/人物与旁白说的对得上吗 / 画面有没有在暗示旁白没说、也没核实的东西；三问有一问答不上来，该帧不许进成片）。四类画面四种标法（实拍无须标；档案画面须标来源与时间地点；示意画面须在画面角落或字幕里标「示意画面」，且禁配具体主张；AI 生成帧/矢量自绘图按第 83 轮穿帮检查过连续性、按第 48 轮勾 AI 生成声明，自绘图须一眼看得出是「图」不是「实拍」）。接缝不许造因果（审片时逐个接缝问一句「这两段拼在一起，观众会推出什么结论？这个结论在核查日志里有吗？」；重点查三处：事件重排 / 反应镜头挪用 / 数据画面错配；数据画面的数必须与旁白数字逐字一致，图表来源进字卡）。仲裁：画面与旁白打架时，判据是事实 ＞ 画面冲击力，改画面、不许改旁白去迁就画面。
- **AI 生成画面的穿帮检查（R83）**：五层审片顺序（故事层常速通看 → 序列层 → 镜头层三速验收 → 帧层 → 交付文件层；故事层不过关不许进帧层）。缺陷四级 + 可观察写法 + 处置分流（Blocker/Major/Minor/Polish；缺陷写法死规矩：时间码 + 可观察的失败，禁「看着 AI 味」「有点怪」；结构性缺陷重生成，局部缺陷裁掉或遮盖，文字错用编辑器换真字）。每个版本独立验收 + 品牌真实表对照（风格元素表 + 核查日志 + 授权登记卡齐才开审）。穿帮检查六项：身份与解剖 / 衣物道具环境 / 物理接触倒影阴影 / 文字数字 / 品牌风格 / 非预期元素。
- **风格一致性审片（R145）**：九项决定收进一页「加伊莎风格元素表 v1」（字幕样式单行 ≤18 字、CPS≤9、断行三原则 / 字体全片一种字幕字体、一种标题字体 / 颜色暖琥珀 #E8A04C 为主强调色、夜蓝 #16283F 为底色、霓虹青 #57C7D4 为冷向点缀，一格只一处强调色 / Logo·标识位不出镜、无 Logo 动画、系列片头标识 1 秒固定位 / 钩子模式第 1 轮三件套同步 / 音乐情绪疏朗钢琴/氛围质感 + ducking / 节奏主片 0.5–1 次/秒、切片 1–2 次/秒 / 封面版式同一版式、3–5 词、主体同侧 / 声音与语调克隆音 + 克制口语、禁播音腔；元素表是参数，模板按表设默认值，改一处全片同步改）。识别力按「声音 ＞ 剪辑风格 ＞ 颜色字体 ＞ Logo」排优先级（Ipsos 倍数：声音线索 8.53 倍、人物 6.01 倍、创意视觉风格 1.67 倍、颜色 1.44 倍、字体 1.41 倍、Logo 只有 1.17 倍，是 2020 年美国视频广告的实测，只作方向；不出镜账号的「人物」锚位由克隆音本身与签名音顶替；预算分配死规矩：声音与剪辑风格先锁死，颜色字体随后，Logo/片头动画不花精力）。每月 12 条并排验漂移 + 发布前 30 秒六项检查（每月一次，把最近 12 条成片含切片的主页网格/封面拼在一起看，记下哪几项漂了，漂移项进台账、改模板参数；发布前 30 秒六项：首帧即钩子 / 字幕样式对表 / 强调色位置对表 / 音乐情绪对表 / 封面版式对表 / 语调一读，六项有一项不过不许发）。

#### C. 合规与勘误：标识三件套，错了就认

- **AI 生成内容标识与平台合规自查（R48）**：标识三件套（片内显式标识「内容由 AI 生成」+ 平台声明勾选 + 隐式标识不被洗掉；按 AI 用量分级标识：A 级全 AI 生成 / B 级 AI 辅助 / C 级轻度修饰，中国口径先标后问）。「疑似」提示出现即记一次合规事故。
- **勘误与更正流程（R73）**：错分五级，级定动作（视频没有「悄悄改文」选项，修复只走三条路：作者补充评论 / 重发修正版 / 下架；错在结论句或标题里的事实错升一级；禁「悄悄重发修正版、不提上一版错了」）。勘误三件套（必须写「更正」二字 + 说清错在哪与对的是什么 + 显著程度不低于原错；原错被大量转发、播放量已过同格式中位数 3 倍以上时，下一条主片开头用一句话提及）。勘误日志 + 时限 + 拍板（24h 内复核、72h 内更正；下架/重发/撤回须用户拍板；同一错误被三个人指出即升一级处理）。
- **版权清关单（R130）**：正式版导出前必须过「版权清关单」（一页纸，未清关不许出片；每行：资产 → 来源/权利人 → 许可类型与编号 → 期限 → 地域 → 媒介 → 署名要求 → 状态：已清关 / 待授权 / 已隔离；状态有一行不是「已清关」，正式版就不许导出；预览版/占位音版不受此限，但文件名必须带 PREVIEW 且禁发布）。TEMP 资产隔离制（占位素材一律标 TEMP_ 前缀；渲染模板里 TEMP 轨道单独一层、颜色标红；正式版导出脚本先扫一遍时间线，扫到 TEMP_ 即报错停下；配乐许可另加三问：覆盖抖音 + 小红书双平台吗 / 含商业用途 / 变现后的使用吗 / 切片再剪辑算同一次使用还是另一次使用；字体同理，单席位字体不许跨项目复用；许可条款截图在购买当时存档）。署名 ≠ 许可 + 用户来料也要验（引用标注只解决「谁说的」，不解决「能不能用」；真实界面截图、他人视频帧、新闻图片、别人做的图表，哪怕画面上写了来源，没有许可就不进成片；用户来料分两类：用户自有资产直接可用、只登记来源，用户转来的第三方素材先隔离、标「待核实」；「AI 生成所以免费」是误区，MJ 生成帧、AI 工具输出的商用范围与再分发条款登记进工具清单）。
