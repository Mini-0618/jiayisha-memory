# 心中之城

## Facts
- 用户 2026-11-11 在商量声音处理时举例“抖音上的心中之城”，问自己的声音怎么处理得像他那样。
- 同日用户试听自己克隆音后明确：“我想要的是 巫师还有心中之城的声音”，把心中之城与巫师财经并列为想要的旁白声线参照。
- 用户没有与心中之城直接往来的证据；这是一次单向的声线参照，不是朋友或合作关系。
- 2026-11-11 已查：其主创是毒舌电影 8 年配音演员，低沉磁性主要靠天生嗓音与专业训练，后期处理约占三成。
- 2026-11-12 01:14 用户最终定版：正式旁白用 Voicebox 克隆「加伊莎」档案，套心中之城向处理链（C 档参数：降调 1 半音以内、加厚、极轻短混响等；D 档过重只作演示、不上长片），MiniMax 平台音色路线搁置。直接克隆其本人声音已明拒（未经同意 AI 克隆真人声音商用侵犯声音权）。
- 2026-11-14：正式配音路线再次确认为本人克隆音＋心中之城向 C 档；本地另做一版「巫师向」8 秒试听（降调约 2 个半音、语速 0.94、低频加厚、压缩——降幅已超 C 档「1 半音以内」口径）仅作待判样品，用户点头前不进正式母带（memory/2026-11-14.md#L89、MEMORY.md#L45）。

## History
- 2026-11-11：用户首次（本窗口内）提出心中之城，作为声音处理与旁白质感的参照举例。
- 2026-11-11：用户在克隆音试听后明确想要巫师财经加心中之城那类声音；Muse 提出声音处理三版方案（A 原声 / B 轻处理 / C 心中之城向），并指出直接克隆二人本人声音不做。
- 2026-11-11 晚：用户先选 B（换平台专业解说音色），后于 2026-11-12 01:14 推翻并最终收口为 Voicebox 克隆「加伊莎」档案加心中之城向 C 档处理；三版处理路线中 C 档被采纳为正式声处理链方向，D 档只作演示。
- 2026-11-14：用户要求用 Groq 声音模型把本人声音生成为「巫师那样」，实测此路不通后改本地处理；正式路线仍为心中之城向 C 档，「巫师向」8 秒试听待用户判断（memory/2026-11-14.md#L89、memory/2026-11-14.md#L99）。

## The relationship
- 用户没有给这段关系命名；没有直接往来、没有对话的证据。
- 实际表现出的关系是单向的声线参照：用户主动拿心中之城的解说声线当加伊莎旁白想要的质感样本，但已明确不克隆其本人声音，最终用本人克隆音套心中之城向 C 档处理去靠近那一类质感。
- 2026-11-14：用户再提“巫师那样”时，正式路线仍守 C 档，「巫师向」另作待判样品、不进正式母带（memory/2026-11-14.md#L89）。

## In common
- 低沉、沉稳、有故事感的职业解说声线质感，是用户 2026-11-11 明确想要的旁白参照；落地为“借质感不借腔调”的 C 档处理链，不违背用户既定声音要求（日常自然声、忌播音腔、保留迟疑感）。
