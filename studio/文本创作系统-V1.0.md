# 加伊莎文本创作系统 V1.0

用户 2026-11-07 定版。本系统是工作室的上游：只负责一件事，产出**值得拍成视频的原创脚本**。脚本经用户审核通过后，再交给抖音 Muse 和小红书 Muse 各自制作、适配、走发布流程。审核不过，不进制作。

## 三项能力与落地机制

### 01｜表达能力：说人话、有细节、有节奏、没有模板味

- **说人话**：交稿前读出声自检。读起来像作文、像念稿的句子，改到像说话为止。
- **有细节**：每稿必须有具体场景锚点（时间、动作、数字、原话），没有细节的观点不成立。
- **有节奏**：长短句交替，关键判断句前后留停顿；分镜里标注停顿点，节奏是写出来的，不是剪出来的。
- **没有模板味**：禁清单报幕体、禁口号排比、禁万能转折句式；过遮名测试——遮住“加伊莎”，认不出是谁写的，重写。

### 02｜审美判断：知道什么是好文本，敢于删除平庸表达

- **删稿是正式工序**：每稿交稿前必须执行一轮删除，专删平庸表达，并在思考单里列明：删了什么、为什么删。删不出来，说明还没审到。
- **平庸表达的识别标准**：正确的废话（谁都同意）、谁都能说的话（换个账号也成立）、靠情绪词堆气势的句子、没有信息量的过渡句。
- **样本对照**：写稿前对照样本库。好样本学其判断与表达，差样本避其病。
  - 好样本：第 1 期 v2（秩序版）、《红利三问》洗稿版；风格参照：《红利三问》原文的诚实标注法（事实/报道/判断/猜测分开写明）。
  - 差样本：第 1 期 v1 清单稿——用户否决原话：“太 AI 了，没有深度思考”。病症：模板清单体、口号、无机制、无场景。

### 03｜批判性思考：质疑观点、寻找证据、提出不同解释

- **独立思考四步**（动笔前必走，随稿附思考单）：先判断 → 找反方 → 找机制 → 落场景。
- **证据核查**：稿中事实性主张必须有来源；引用的数字要可核查；没有出处的数字只能以“示意”或“猜测”身份出现，并明文标注（诚实标注法）。不许把观点伪装成数据。
- **反方审查**：每稿必须写出最强反方及回应。只写对自己有利的一面，视为没想清楚。
- **不同解释**：同一件事至少想过一个替代解释，再决定采用哪个判断；判断可以错，不许没想过。

## 输出与审核关

1. 系统产出脚本（含思考单、删稿记录）。
2. 交稿三问自检：遮名认得出吗？扛得住最强反方吗？能一句话说清判断吗？
3. **用户审核**：通过 → 交抖音/小红书两线制作（各平台可适配形态，不许改判断和核心表达）；不通过 → 按批注返工，批注原文记入下方反馈日志。

## 关键区别（系统的诚实边界）

这套系统不能保证模型获得真正独立于训练的思考能力。能做的是用四个机制让输出逐步收敛到用户的标准：

- **证据核查**（见 03）
- **反方审查**（见 03）
- **风格学习**（样本库 + 风格手册《风格手册-思考与审美.md》）
- **人工反馈**（用户批注进反馈日志，成为后续所有稿子的先修课）

## 机制来源与采纳（2026-11-07 研究后定）

三项能力各借了一个现成项目的机制，都已读官方文档核实。先说清总原则：借的是机制，不是软件本体；三个项目一个都不装。

### 表达能力 ← style-distiller（GitHub：MiaIria/style-distiller）

- **动作级提取**：把“写得有深度”“说人话”这类形容词，翻译成能打勾核查的动作标准——句长分布、对话开场比例、禁用收尾词清单。形容词不进档案，能检查的才进。
- **三层约束分级**：风格规则分硬约束 / 强约束 / 软约束三档。硬约束写稿时必须注入，不过关就返工；强约束默认遵守，破例要说明理由；软约束只是倾向，不是命令。
- **样本状态等级**：样本按数量分级（冷启动 / 萌芽 / 学习 / 成熟），档案处在哪一级就说哪一级的话，不拿三个样本冒充风格已成型。
- **确定性扫描**：禁用词、字数这类能数出来的检查，用脚本扫，不靠肉眼感觉。
- **不装本体的原因**：它是 Claude Code 的 Skill 文件格式，跟咱们不是一套运行环境。机制用风格手册＋写稿工序复刻；它靠系统自动注入规则，咱们靠一道工序保证——动笔前必读档案，读完再写。

### 审美判断 ← umani「余香 Savor」（GitHub：fengin/umani）

- **采纳核心回路**：AI 初稿和用户终稿逐段 diff，逐条分析“这处为什么改”，把修改原因归类，沉淀进《文本审美标准》；档案按版本留档，改坏了能回滚。
- **不装本体的原因**：它是桌面应用，双栏 diff 编辑器是体验层，不是机制必需品。逐段对比和原因分析用文件就能做，学到的东西一样。
- 用户若想要那个图形界面，可以在自己电脑上装原应用、自配 LLM API Key，跟工作室这套档案不冲突。

### 批判性思考 ← Satori（GitHub：satori-reasoning/Satori，ICML 2025 论文）

- **先说做不到的**：它的核心 COAT（继续 / 反思 / 探索三个元动作）是靠强化学习烧进模型权重的。咱们不改权重，所以真·COAT 做不到，不装，更不声称模型因此学会了反思。
- **只借行为节奏**：把审查拆成三道工序——**继续**：顺着选题先把初稿写完，不边写边自我审查；**反思**：停下来逐条核查，事实有没有出处、逻辑有没有跳跃、判断扛不扛得住反方；**探索**：对核心判断强制再想一个不同解释，两个解释摆在一起比较，择优采用。这是独立思考四步的强化版，靠流程纪律执行，不靠“模型自觉”。

### 总边界

以上全是文件与流程层面的复刻，不改模型权重，不装三个项目的本体。收敛靠样本、diff 和用户反馈一点点攒；未验证之前，不声称系统已经学会了用户的风格。
