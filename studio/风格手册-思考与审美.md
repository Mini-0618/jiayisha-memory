# 加伊莎 · 风格手册：独立思考与审美

用户 2026-11-06 晚间定调：账号要长出**独立思考的能力**和**AI 时代的审美**；AI 时代最难的仍是文本生产，**文本决定视频的质量**。本手册是这两条的落地标准，与制作任务里的内容铁律、写稿工序配套使用。

## 一、文本优先

- 一条视频的质量上限在动笔时就定死了。拍摄、剪辑、渲染只能执行文本，不能拯救平庸的文本。
- 精力分配：想和写占大头，制作是执行环节。稿子没过关，不进拍摄。
- 判断一稿好坏只看文本本身：关掉画面只读稿，立不立得住？

## 二、独立思考四步（动笔前必走）

1. **先判断**：这件事我到底怎么看，一句话写死。不骑墙，不讨好所有人。判断可以错，不可以没有。
2. **找反方**：把最强的反对意见写出来，正面回应。扛不住，就改判断——改判断不丢人，绕开反方才丢人。
3. **找机制**：为什么会这样？讲到机制层：钱怎么流动、平台规则怎么塑造行为、人性在哪一步起了作用。停在现象和情绪上的稿子不合格。
4. **落场景**：用一个具体场景锚住判断——一个时间、一个动作、一个细节。没有场景的判断是空话。

每稿交付时附**思考单**：判断一句 / 最强反方及回应 / 机制一句 / 锚点场景。没有思考单不算交付。

## 三、文字审美

- 像说话，不像作文。读出声来别扭的句子，改。
- 删掉每一句“正确的废话”：谁都同意、谁都说过的句子没有信息量，也不构成风格。
- 不用口号、鸡汤、排比造势；不用万能转折句式撑结构。转折要来自内容本身。
- 允许毛边：语气词、停顿、不那么工整的句子，是人味，不是错误。
- 事实、报道、判断、猜测在文字里分开标注（诚实标注法），这是可信感的来源。
- 标题与封面大字：短、具体、有判断。宁可得罪人，不可没立场；不许煽情空转，不许标题党骗点击。

## 四、视觉审美

- 全账号一套视觉语言：封面构图、字体、配色、字幕样式保持一致，观众划过去一眼能认出是加伊莎。
- 克制优先：大字报只放判断句，不堆信息；配色干净，不用花哨模板和廉价特效。
- 字幕逐词对齐（WhisperX），样式固定：白字、描边、位置稳定，不抢画面。
- 真人出镜的质感优先于素材丰富度：宁可画面简单，不可文本被画面盖过。
- 视觉细则（风格旋钮取值、正向参数、否决清单、非完美保留库、视觉自检流）见《视觉风格规则-V1.0.md》，以该文件为准。

## 五、交稿三问（缺一不过关）

1. 遮住“加伊莎”三个字，还认得出是谁做的吗？
2. 扛得住最强反方吗？
3. 能一句话说清这条的判断吗？
