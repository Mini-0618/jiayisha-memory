# 投喂 29：AI 编程智能体悬赏平台 6 个（外部稿，用户 2026-11-16 转来，疑似 ChatGPT 输出，原样存档）

有，而且现在已经出现了专门让 AI 编程智能体（AI Agents）自己接任务、写代码、参加竞赛、赚取奖金 的平台。

我查了截至 2026 年 11 月 16 日的信息。下面这几个值得关注，尤其适合你想打造的「超级个体中心」，让 Codex、Claude Code、Nova 等智能体组成赚钱团队。

## 最值得关注的 6 个平台

1. make.fun（https://make.fun/）
最符合你的目标。专门为 AI 编程智能体设计的悬赏竞赛平台。Agent 能通过 API/MCP 自主发现任务、写代码、提交作品，获胜后领取 USDC 奖金。官网列有约 250–1,325 美元的不同悬赏项目，部分任务免费参与。奖金并非保底收入。

2. Superteam Earn for Agents（https://superteam.fun/earn/agents/）
明确开放 Agent 专用任务。AI 可以自主发现允许智能体参与的悬赏、项目和黑客松，并提交成果，但最终奖金由人类操作者认领。

3. Opire（https://opire.dev/）
GitHub 开源编程悬赏。开发者解决 Issue、提交代码，验收后获取奖励。适合让 Codex、Claude Code 辅助完成真实编程任务，但需要逐项核实 AI 使用规则。

4. Algora（https://algora.io/）
以 GitHub Issue 为中心的编程赏金平台，通常在代码被接受后发放奖励。但部分公开悬赏看板目前没有开放任务，需核对实际库存。

5. DoraHacks（https://dorahacks.io/）
面向开发者的全球黑客松与项目竞赛平台，包含 AI Agent、应用开发和 Web3 项目。有现金奖金，但一般需要按比赛规则报名、提交和评审。

6. Agentizable（https://agentizable.ai/）
面向自主智能体的赏金市场，支持 Agent 寻找任务、交付、验证和以 Base 链 USDC 结算。目前公开任务列表无法正常刷新，实际可接任务量尚不能确认。

## 怎么让你的 AI 自己去赚钱？

建议先从 make.fun + Superteam Earn 开始，而不是同时接入十几个平台。

结构：超级个体中心 / AI CEO 统筹任务、成本、收益与风险 → 任务搜索 Agent 自动寻找悬赏 → 编程 Agent 生成代码并测试 → 审查 Agent 验证质量与合规 → 提交合规作品 → 平台验收 → 领取奖金。涉及付款、钱包授权和高风险操作由你批准。

需要明确：这不是保证赚钱的系统。竞赛可能落选，编程任务可能被拒收，模型调用也会产生费用。make.fun 公布了链上支付记录，但其实际收益和可靠性仍需要独立验证。

建议：先做一个零报名费、有限 API 预算的真实任务实验。让 AI 自动选题、编程和测试，你审核提交，确认第一笔奖励确实到账后，再逐步扩大自动化程度。
